## Introduction

Use sequences to send emails from a connected mailbox and organize outreach across LinkedIn and phone calls. Email steps send automatically. LinkedIn and call steps create tasks for you to complete.

Connect a mailbox from **Integrations** before sending email. See [Email Integrations](/email-integrations) for setup and mailbox access.

## Sequences overview

Open **Sequences** from the left-hand menu. This page shows your sequences, outreach performance, and scheduled activity. Select a sequence to view its candidates and results, or select **New sequence** to create one.

## Creating a sequence

1. Open **Sequences** and select **New sequence**.
2. Choose how to start:
   - Select a suggested project, or use **Choose project**, to generate a sequence with AI using that project's context.
   - Select **Build from scratch** to start with a blank sequence.
   - Use **Clone existing sequence** to start from a sequence you already have.
3. Review and edit the sequence in the composer.

<Frame>
  ![New sequence creation options with project choices, Build from scratch, and Clone existing sequence highlighted](/images/sequences/composer-create-sequence.svg)
</Frame>

The composer brings together two ways to edit:

- **Composer chat:** use the side panel chat to draft or revise your outreach in natural language. Answer its questions when more context is needed.
- **Sequence canvas:** edit the title, messages, senders, step types, and timing directly. Use the numbered step rail to move between steps.

You can minimize Composer chat to make more room for the sequence.

<Note>
  Changes save automatically. Check the **Last saved at** indicator, then select **Done** to close the composer. Creating a sequence does not enroll candidates; [add profiles](/add-profiles) when you are ready to start outreach.
</Note>

### Title the sequence

Click the sequence title at the top of the composer and enter a name. Use a name that helps your team recognize the role or project.

### Edit the number of steps and each step's schedule cadence

Select **Add step** in the step rail or below the sequence to add a step. Use **Delete step** on a step's card to remove it. You can also ask Composer chat to add or remove a step; it asks you to confirm before removing one.

Use the timing control above each step to set its schedule:

- **First step:** open **Start immediately** to choose **immediately**, **next business day**, **soonest at**, or **after**. Configure the timing for the option you select.
- **Later email steps:** open the **Wait** control. Set the delay in days, business days, weeks, or months, then review **Send at** and **Timezone**.
- **Manual tasks:** use the **Create** timing control to choose when the task is created.

<Frame>
  ![Follow-up delay, send time, and timezone controls highlighted in blue](/images/sequences/composer-step-schedule.svg)
</Frame>

### Select the step type

Open the step-type dropdown beside the step number. Choose **Email**, **Connection Request**, **LinkedIn Message**, or **Call**.

<Warning>
  Only email steps send automatically. Other step types create a task, and the sequence pauses until you complete or skip that task.
</Warning>

### Choose the sequence sender

Use **From** on each email step to choose a connected mailbox. Mailboxes without access are identified in the dropdown. You need permission to send from a mailbox before starting outreach; see [Email Integrations](/email-integrations) for mailbox permissions.

You can use a different sender for each step, such as a recruiter for the first email and a hiring manager for a follow-up. When a sequence uses multiple senders, review the **Single thread** and **Multi thread** options:

- **Single thread:** senders participate in the same conversation. Additional senders are CC'd for awareness.
- **Multi thread:** each sender starts a separate thread. Review the subject for each new email. A later step from a new sender starts a new thread by default.

A follow-up in an existing thread shows **Reply to Step** and the step number instead of a new subject field.

### Customize the subject line

Edit **Subject** on an email that starts a thread. Use the **Cc** and **Bcc** control beside the subject to show those fields.

You can insert a candidate variable, such as **First Name**, to personalize the subject. Review the resolved subject in the email preview before sending.

### Customize the email text

Edit the message directly on its step card. The formatting toolbar supports bold, italic, lists, links, images, and other text formatting. Add a scheduling link as a hyperlink when you want candidates to book time with you. As a best practice, save the scheduling link for a later step rather than the first email.

Use the quick-add controls above the body to insert an **AI command**, a **Network mention**, or a variable. Open **Show all variables** for more choices. The [inline composer](#inline-composer-slash-menu) also makes these tools available while you type.

Select **Snippet** below the message to reuse saved text. Select **Add attachment** to attach a file to an email step. You can attach up to 3 files per step, 4 MB each.

<Warning>
  Attachments can hurt deliverability on cold outreach. Link to the file where you can, and keep attachments for later steps or warm conversations.
</Warning>

### Include a signature

Use the sender signature dropdown on an email that starts a thread. Choose a saved signature, or select **Add sender signature** when none is selected. Review the signature in the email preview, especially after changing the sender.

To create a signature, see [Manage Account](/manage-account).

### Include a candidate unsubscribe link

Enable **Include unsubscribe** at the bottom of an email step to include an opt-out link for the recipient.

### Preview and test your sequence

1. Select **Preview** on the step you want to review.
2. Use the contact selector next to **To** to check the message for a sample contact. Review the subject, resolved variables, AI personalization, signature, and any footer.
3. Under **Send yourself a test email**, enter your email address and select **Send Test**. Test messages include **[TEST EMAIL]** in the subject.
4. Close the preview to return to editing.

You can also ask Composer chat, "Send me a test of step 2." Specify the email step you want to check. The test uses the current message, including your latest edits.

<Frame>
  ![Email preview with the contact selector and test email controls highlighted](/images/sequences/composer-email-preview.svg)
</Frame>

Review each step before enrolling candidates. When the sequence is ready and the latest changes are saved, select **Done**. Then follow [Add Profiles](/add-profiles) to review recipient-specific messages and start outreach.

## Generate with AI

To create an AI-generated sequence, choose a project when creating a sequence. Use **Composer chat**, the side panel on the left, to provide details and refine the result.

When available, AI uses your project's intake notes, linked job, and search criteria, along with company information, your writing style, and relevant past team sequences. Search results and shortlisted profiles can help it understand the target audience. It can also consult the web and tools you have connected for additional context.

Describe what you want in the chat. Useful details include:

- The role, company, and reasons a candidate might be interested.
- The number and type of steps, and the spacing between them.
- The tone, length, and language of the messages.
- Whether to ask for a reply or include a scheduling link.

For example: "Draft three short emails for this role in a friendly tone. Space the follow-ups three business days apart and ask candidates to reply if they are interested."

Composer chat may ask for missing details or suggest changes, such as adding follow-ups, a LinkedIn step, or a hiring-manager sender. Choose an option, type your own answer, or select **Skip** to move on.

Review the AI-generated sequence in the canvas. Use Composer chat to revise the copy or change steps, senders, signatures, and timing. You can also update sequence settings such as its title, timezone, and email threading. For example:

- "Make the first email more concise."
- "Wait three business days before step 2."
- "Send the final email from our hiring manager's mailbox."

Changes appear directly in the canvas, where you can also edit them yourself. Use the stop button in Composer chat to interrupt a request, then review any changes already made. The conversation stays with the sequence so you can continue when you reopen it.

<Note>
  Review generated copy for accuracy before sending, including claims about your company and the candidate's experience. Generating a sequence is separate from adding candidates to it.
</Note>

### Revise selected text

Select a passage in a message to open its editing menu:

- **Proofread** fixes the selected copy.
- **Make concise** shortens it.
- **Adjust tone** offers **Casual**, **Direct**, and **Warmer**.
- **Ask the Composer** lets you give custom instructions in Composer chat.

The **Selected text · Step N** indicator shows which passage your chat request will change. Select its **×** to clear the selection before making a broader request.

## Create or edit a sequence with a sourcing Agent

You can also work on outreach in your [Juicebox Agent](/juicebox-agents) conversation. Ask the Agent to create a sequence for the role or revise an existing one—for example, "Create a three-email sequence for this role" or "Make the first email shorter."

The sequence opens in a **Sequence** side pane beside your existing Agent chat. Give feedback in that conversation or edit the messages, senders, and timing directly in the pane. Changes save automatically; review each step with **Preview** before using the sequence for outreach.

This workflow uses your sourcing Agent conversation. **Composer chat** is the side panel you use when opening the standalone composer from **Sequences**. See [Juicebox Agents](/juicebox-agents) for outreach setup and sourcing settings.

## Inline composer (slash menu)

Type **/** in a message body to open quick adds. The menu includes:

| Option | What it does |
| --- | --- |
| **Edit with AI** | Rewrites the whole step. In Composer chat, choose an option such as **Proofread** or **Make it more concise**, or type your own instruction. |
| **AI Command** | Opens the AI command picker to insert personalized copy at the cursor. |
| **Network Mention** | Adds a mention of a relevant mutual connection. See [Network Sourcing](/network-sourcing#use-network-snippets-to-personalize-outreach). |
| **Variables** | Inserts candidate or sender details, such as **First Name**, **Current Company**, or **Sender First Name**. |
| **Snippets** | Inserts saved text, with options to show all snippets or create one. |

Press **/** again if you want to insert a literal slash.

### AI commands

Select the **AI command** chip above the message, or type **/** and choose **AI Command**. Choose the **Work experience** or **Skills** preset, or write a clear, concise command and select **Done**.

For example: "Write one sentence connecting the candidate's relevant engineering experience to this role."

<Frame>
  ![AI command picker with the Work experience and Skills presets, custom command field, and Done highlighted](/images/sequences/composer-ai-command.svg)
</Frame>

An AI command is an instruction for per-candidate personalization at the place you insert it. It differs from asking Composer chat to rewrite the shared sequence text. Use **Preview** to inspect the resulting copy for a sample contact.

Keep commands specific about the topic and desired length. Make sure the instruction works across the candidates you plan to contact. AI commands run with context from the whole sequence, so personalization in a later step builds on earlier steps instead of repeating the same angle.

## Editing an existing sequence

From **Sequences**, open the sequence's **…** menu and select **Edit**. Use the same Composer chat and step cards to revise the sequence.

If Juicebox prompts you to apply edits to candidates already enrolled, review the choice before applying them. Only outstanding steps can change; a message that has already been sent is not rewritten. To make an edit for one candidate, see [Add Profiles](/add-profiles#view-email-history).

## Non-email steps

Choose **Connection Request**, **LinkedIn Message**, or **Call** from the step-type dropdown. Use **From** to choose the task owner. For a connection request, enable **Include custom note with connection request** if you want to prepare a note. 

You can add a **Call** step even when a candidate has no phone number on file. The task is still created for the owner, who can find a number or skip the step.

These steps create manual tasks. Juicebox does not send the LinkedIn message or make the call for you. When a task is due, the owner receives a notification and completes the action on LinkedIn or by phone.

When a task has been triggered, it appears on your home page. From here, you can execute your task or filter by status, task type, or project.

<Frame>
  ![Home page task list with filters for status, task type, and project](/images/sequences/tasks-home.png)
</Frame>

After completing the task, select **Mark as completed** or **Skip** to resume the sequence for any remaining steps. While the task is pending, the sequence stays paused.

<Frame>
  ![Mark as completed and Skip options for a pending task](/images/sequences/complete-task.png)
</Frame>

## Creating a sequence from your shortlist

Select candidates in your project's shortlist and choose **Add to Sequence**. From the sequence picker, you can select an existing sequence or create a new one.

Review the sequence in the composer, then return to enrollment to choose contact preferences and check each candidate's personalized messages. See [Add Profiles](/add-profiles) for the full enrollment flow.

If a connected mailbox is required, follow the prompt to connect one before sending email.

## Pausing, resuming, or stopping a sequence

If you want to stop, pause or resume a sequence, you can select the individual sequence from the Sequences homepage. Once that sequence has been selected, you can bulk select all candidates next to **Full name** or individually select the candidates you want to stop/resume the sequence for.

<Frame>
  ![Candidate selection within a sequence for pausing, resuming, or stopping](/images/sequences/pause-resume-stop.png)
</Frame>

Sequences can be paused or stopped in a few different ways:

- **Automatically**
  - When a candidate replies to your outreach, the sequence will automatically stop for that candidate. This includes both email replies and LinkedIn Recruiter InMail replies.
  - If the mailbox is disconnected from Juicebox, all sequences from that mailbox will automatically pause.
- **Manually**
  - You can manually **pause**, **resume**, or **stop** a sequence at any time, either for a single candidate or for all candidates.

<Note>
  Juicebox detects InMail replies through the email notifications LinkedIn sends when a candidate responds to an InMail. Detection works only if both of the following are true:

  1. The mailbox connected to Juicebox is the same mailbox where you receive LinkedIn's InMail reply notifications.
  2. Email notifications for InMail responses are turned on in your LinkedIn settings.

  If either condition is not met, Juicebox cannot detect the reply. Check both for each connected mailbox.
</Note>

If Juicebox finds an InMail or LinkedIn message reply that it cannot match to a sequence, the reply still appears in the candidate's profile activity. The sequence does not stop, and the candidate's status does not change.

Manual controls are also helpful if you want to delay outreach, make edits, or stop follow-ups after receiving a response through another channel (like a phone call).

1. **Pause**: Temporarily halts all remaining steps in the sequence. Use this if you want to resume sending later.
2. **Resume**: Continues the sequence from the next unsent step for each candidate.
3. **Stop**: Permanently ends the sequence for the selected candidate(s). No further steps will be sent. Use this when a profile is no longer relevant, has opted out, or has already engaged outside of email.
