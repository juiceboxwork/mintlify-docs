## Analytics overview

As a Juicebox Enterprise Admin, you have visibility into how your team is utilizing Juicebox across projects, agents, outreach, and individuals. These analytics can help you understand how to optimize workflows, strengthen collaboration or adoption, and maximize the value of Juicebox.

To make these insights easy to navigate, analytics are exportable for sharing and organized into four core categories:

- **Usage:** Understand team activity and feature adoption
- **Projects:** See your funnel performance by project
- **Outreach:** Track performance across sequences and outreach
- **Agents:** Manage and track activity across your AI Agents

![Analytics](https://raw.githubusercontent.com/juiceboxwork/docs/kb-migration/images/analytics/Analytics.png)

**To understand your analytics, select one of the dropdowns below to learn more.**

### 📊 Usage analytics

Usage analytics helps admins and team leads understand where value is being generated by breaking out metrics on how the platform is being used over time and by whom.

![Screenshot 2026-01-07 at 11.47.22 AM](https://raw.githubusercontent.com/juiceboxwork/docs/kb-migration/images/analytics/Screenshot_2026-01-07_at_11-47-22_AM.png)

**This view is designed to answer questions like:**

- Who is actively sourcing in Juicebox?
- Which features are driving the most usage (search, autopilots, exports)?
- How are credits being consumed across the team?
- Are there opportunities for enablement or optimization?

**With key metrics including:**

- **Searches run:** Total number of searches created
- **Autopilots run:** Total number of autopilots ran
- **Profiles viewed:** Total number of individual profiles reviewed
- **Profiles shortlisted:** Total number of profiles saved / qualified across projects for further engagement or sharing
- **Profiles exported:** Total number of profiles exported back to your ATS and/or downloaded via a CSV
- **Credits used:** Total number of contact credits used

**For a more granular breakdown, filter usage analytics by:**

- User or [member tags](#filter-by-member-tags)
- Date range
- Time period (e.g., days, weeks, months)

#### Usage by user leaderboard

The **Usage by user** leaderboard breaks out activity for each teammate, with a **Total** row at the bottom. Use the outreach rate columns to compare how well each teammate's outreach converts, not just how much they send.

- **Replied:** Shows the number of replies, with `X% of contacted` underneath. This is the user's reply rate.
- **Interested:** Shows the number of interested replies, with `Y% of replies` underneath. This is the share of replies that were interested.
- **Interested % of contacted:** Shows interested replies as a percentage of candidates contacted. Click the column header to sort teammates by this rate. Users with no contacted candidates show `0%`.

Juicebox calculates the rates in the **Total** row from the summed counts across all users. It does not average each user's rate. For example, if one user has 1 reply from 10 contacted and another has 9 replies from 90 contacted, the total reply rate is 10%.

When you export the leaderboard as a CSV, the file includes matching rate columns: **Replied % of contacted**, **Interested % of replies**, and **Interested % of contacted**.

### 📈 Projects analytics

Project analytics provides visibility into recruiting performance at the project level. This view helps you understand how each project is progressing or where efforts may need to be prioritized.

![Screenshot 2026-01-07 at 11.55.06 AM](https://raw.githubusercontent.com/juiceboxwork/docs/kb-migration/images/analytics/Screenshot_2026-01-07_at_11-55-06_AM.png)

**This view is designed to answer questions like:**

- How many projects have been created in Juicebox?
- How many candidates have been shortlisted for each project?
- How quickly are candidates being contacted?
- How is a specific project performing, and where should efforts be prioritized?
- Which projects is a particular user actively working on?

**With key metrics including:**

- **Total projects:** Total number of projects created
- **Shortlisted:** Total number of candidates shortlisted
- **Contacted:** Total number of candidates contacted
- **Average time to contact:** How long it takes to contact a candidate
- **Replies:** Total number of candidate replies
- **Interests:** Total number of interested candidate replies

**For a more granular breakdown, filter project analytics by:**

- Project
- User or [member tags](#filter-by-member-tags)
- Date range

### 💌 Outreach analytics

Outreach analytics helps you measure and optimize the performance of your email sequences and outreach efforts. These insights show how candidates engage with your messaging, where drop-off occurs, and how consistently your team is engaging with talent.

![Screenshot 2026-01-07 at 12.13.57 PM](https://raw.githubusercontent.com/juiceboxwork/docs/kb-migration/images/analytics/Screenshot_2026-01-07_at_12-13-57_PM.png)

**This view is designed to answer questions like:**

- Are my email sequences performing well overall, or only within certain projects?
- Where are candidates disengaging?
- Which messages or sequences need to be updated or tested?
- Is my team generating enough interested candidate responses across projects?

**With key metrics including:**

- **Profiles contacted:** Number of candidates who have been sent at least one sequence step. The card also shows the number of sequence runs behind that count.
- **Open rate:** Percentage of contacted sequence runs that candidates opened
- **Click rate:** Percentage of contacted sequence runs where candidates clicked a link
- **Reply rate:** Percentage of contacted sequence runs that candidates replied to
- **Interest rate:** Percentage of contacted sequence runs where candidates replied that they were interested in your project / opportunity
- **Bounce rate:** Percentage of contacted sequence runs that were undeliverable. Project and user tables count each bounced run once, even if more than one email in the run bounced.
- **InMail Replies:** Total number of LinkedIn Recruiter InMail replies received from candidates, counted separately from email replies

<Note>
  Juicebox detects InMail replies through the email notifications LinkedIn sends when a candidate responds to an InMail. Detection works only if both of the following are true:

  1. The mailbox connected to Juicebox is the same mailbox where you receive LinkedIn's InMail reply notifications.
  2. Email notifications for InMail responses are turned on in your LinkedIn settings.

  If either condition is not met, Juicebox cannot detect the reply. Check both for each connected mailbox.
</Note>

#### How outreach rates are calculated

Open, click, reply, interest, and bounce rates all use contacted sequence runs as the denominator. A run counts as contacted once Juicebox has sent its first step. Juicebox excludes the following runs from the denominator:

- Runs that were cancelled or stopped early, including runs cancelled because the mailbox was disconnected
- Active or paused runs that are still waiting on their first step

The numerators don't change. Opened, clicked, and replied counts still include every run where that engagement happened. Each rate card shows the raw counts in parentheses, for example `(42/180)`, where the second number is the contacted total.

<Note>
  Rates may look higher than in earlier reports if your team has many cancelled runs or runs scheduled but not yet sent. Those runs no longer lower your rates.
</Note>

#### Not interested reasons

The **Not interested reasons** chart shows why candidates declined your outreach. Use it to spot patterns, such as compensation or location concerns, that you can address in your messaging or role setup. The chart follows the page's date, sequence, project, started by, and inbox filters.

Juicebox groups each not-interested reply into one of these reasons:

| Reason | Description |
| --- | --- |
| Not job hunting | Happy where they are, or not considering new opportunities. |
| Bad timing | Busy, just started a role, or wants to wait. |
| Location | Location, relocation, commute, or remote/hybrid expectations. |
| Role fit | The role's responsibilities, seniority, title, or function isn't right for them. |
| Company fit | The company's industry, stage, reputation, or mission isn't right for them. |
| Compensation | Pay, equity, or other financial terms are the main obstacle. |
| Wrong person | The email reached the wrong person. |
| Personal reasons | Personal circumstances are the main reason they declined. |
| Other | A reason that fits none of the above, or one they didn't make clear. |
| Not categorized | Marked not interested by hand, or a reply Juicebox couldn't categorize. |

Each reason shows its count and share of not-interested replies. Hover the info icon next to the chart title to see the reason descriptions.

To review the replies behind a reason:

1. Click a reason in the chart.
2. Review the matching replies in the dialog. Each row shows the candidate, sequence, reply summary, who added them, and when they replied. Replies under **Not categorized** have no summary. The dialog applies the same filters as the page.
3. Click a row to open the candidate's full profile on the **Sequences** tab. Close the profile to return to the dialog.

The dialog lists only replies in sequences you can open. If other matching replies are in private sequences, the dialog shows how many are hidden.

**For a more granular breakdown, filter outreach analytics by:**

- Sequence
- Project
- Started by (user or [member tags](#filter-by-member-tags))
- Inboxes
- Date range
- Time period (days, weeks, months)

### 🤖 Agent analytics

Agent analytics give you visibility into agent-led sourcing and outreach as you scale your hiring efforts. This view helps you ensure automation is driving results while maintaining control over candidate quality, approvals, and outcomes.

By monitoring how agents source, qualify, and surface leads, you can confidently scale automation, fine-tune agent configurations, and identify opportunities to improve efficiency without sacrificing relevance. To focus on just your agent-backed projects, use the **Show agents only** filter on the projects home screen.

![Screenshot 2026-01-07 at 1.17.45 PM](https://raw.githubusercontent.com/juiceboxwork/docs/kb-migration/images/analytics/Screenshot_2026-01-07_at_1-17-45_PM.png)

**This view is designed to answer questions like:**

- How effective are my agents at finding relevant candidates?
- What is my approval rate across agents, and how does it trend over time?
- How many interested candidates are agents generating?
- Are agents correctly configured based on approved vs. disapproved leads?
- How many leads are pending approval or still awaiting action?

**With key metrics including:**

- **Leads approved:** Total number of agent sourced candidates approved
- **Leads disapproved:** Total number of agent sourced candidates rejected
- **Approval rate:** Percentage of all agent sourced candidates approved
- **Interested replies:** Total number of agent sourced candidates who replied that they are interested
- **Number of agents:** Total number of agents created
- **Paused agents:** Total number of paused agents
- **Active agents:** Total number of active agents
- **Pending leads:** Total number of candidate reviews outstanding

**For a more granular breakdown, filter agent analytics by:**

- Agent
- Owned by (user or [member tags](#filter-by-member-tags))
- Date range
- Time period (days, weeks, months)

### Filter by member tags

Use member tags to scope analytics to a group of teammates, such as a recruiting team or region, without picking each user individually. Tag filters are available in the **Users** filter on Usage and Projects analytics, the **Started by** filter on Outreach analytics, and the **Owned by** filter on Agent analytics.

1. Open the filter and select **By tags**.
2. Select one or more tags.
3. Choose how Juicebox matches the selected tags:
   - **Match any** (default): Includes members who have at least one of the selected tags.
   - **Match all**: Turn on **Match all selected tags** to include only members who have every selected tag. A **Match all** badge appears on the filter.

Juicebox saves your tag selections and match setting in the page URL, so shared links open with the same filters applied. Selecting specific users under **By users** clears any tag filters.
