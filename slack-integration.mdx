## Overview

Recruiters and hiring managers already coordinate on roles in Slack, but candidate profiles live in other tabs. Juicebox for Slack closes that gap: connect a Project or Agent to the channel where the team works, and updates show up at the right time — right in the thread, ready to act on.

Juicebox for Slack lets you:

- **Notify, answer, and act** on existing projects, sequences, and Agents
- **Review and surface leads** produced by an existing Agent or shortlist
- **Act faster** on common actions — especially on mobile

It is not a replacement for the full Juicebox product. You cannot start new sourcing searches from a Slack prompt or run open-ended talent strategy from Slack.

## Set up in three steps

<Steps>
  <Step title="Connect Slack to Juicebox">
    Navigate to the **Integrations** tab and connect the Slack integration to Juicebox. This creates a single workspace connection.
  </Step>
  <Step title="Link a project or Agent">
    From the **Agents** or **Projects** tab, connect the relevant project or Agent to the Slack channel where the team collaborates on that role.
  </Step>
  <Step title="Tag @Juicebox in the channel">
    Get started by asking Juicebox what it can do in Slack. Type:

    ```
    @Juicebox, what can you do?
    ```

    The integration will now surface notifications, project updates, and shortlist review requests in that channel.
  </Step>
</Steps>

## Core capabilities

### Review leads directly in Slack channels

When a review is requested, Slack posts a candidate carousel — approve, skip, or reject each profile.

- Add context during the decision; feedback syncs back and informs the Agent's learning and the platform.
- Carousels hold up to 10 cards. Press **See More** to generate more profiles at the end of the carousel.
- Shortlist reviews and Agent leads follow the same flow.

### Get project and sequence notifications

Once a Project or Agent is connected to a Slack channel, activity shows up in that channel:

- New Agent leads ready for review, or interested replies from an email sequence
- Project activity such as name changes or collaborators being added or removed
- Project activity summaries on a configurable cadence

You can also chat directly with Juicebox in Slack to get project notifications and status updates.

### Ask @Juicebox for project and Agent analytics

Tag `@Juicebox` in a channel to get quick answers without navigating dashboards:

- Pending, approved, or reviewed lead counts at a glance
- Outreach volume — how many people contacted or added to a sequence
- Pipeline, project, Agent, or sequence health, answered in the thread
- What happened to a profile after it was approved

### Take profile actions and create tasks

Manage profiles and follow-up straight from Slack:

- Add a **note** or update **tags** on a profile
- Create a **reminder or task** and assign it to a teammate in the channel — the assignee is tagged in Slack, and the task and note live in Juicebox
- Share a **LinkedIn URL** and add it straight to a project shortlist

## Actions to try in Slack

| Action | Example prompt |
| --- | --- |
| Lead review | `@juicebox, show me the pending leads for [Agent].` |
| Agent status | `@juicebox, how is [Agent] doing?` |
| Approvals | `@juicebox, how many leads did we approve this week for [Project]?` |
| Outreach | `@juicebox, how many people have we contacted in [Sequence]?` |
| Profile history | `@juicebox, what happened to [Profile] after we approved them?` |
| Shortlist add | `@juicebox, add this LinkedIn profile to the shortlist for [Project].` |
| Pipeline health | `@juicebox, what is the current health of [Project]?` |
| Task | `@juicebox, assign [Teammate] a task to follow up with [Profile] by Friday.` |

## Recommended workflows

| Workflow | Starts with | What you do in Slack | Why it matters |
| --- | --- | --- | --- |
| **Shortlist review (Slack / mobile)** | A "new leads ready" notification | Open the carousel; approve, skip, or reject; add feedback | Faster lead review, especially from mobile, without the desktop product |
| **Hiring manager alignment** | A review request | Review profiles, ask for current status | Removes barriers for hiring managers to access Juicebox |
| **Candidate discussion to action** | A LinkedIn profile shared in channel | Add to shortlist, tag, add a note, assign follow-up | More structured follow-through from Slack conversations |
| **Project or Agent status check** | A leader asking for an update | Ask about approved leads, outreach, history, or pipeline health | A quick, current answer without navigating dashboards |

- **Recruiting Ops** — Embed common recruiting workflows into Slack while preserving structured data and actions in Juicebox.

## Best practices

- The integration creates one workspace connection, but supports unlimited Slack channel to project or Agent mappings. We recommend **one channel per project or Agent**, though some teams put everything in a single channel.
- Notifications are scoped to the channel — anyone in the channel gets them. Some notifications (project renamed, collaborators added or removed) can't be disabled. The project activity summary has a configurable cadence — it defaults to weekly, and can be set to daily or monthly.
- You only need to tag `@Juicebox` when starting a new thread, not on every message within the thread.
- DMing Juicebox directly works for status and analytics questions, and works for users without a Juicebox seat (view-only). Lead review cannot happen in DMs.
