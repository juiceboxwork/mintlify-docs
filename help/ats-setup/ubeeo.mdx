## About the integration

Connect Ubeeo to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. This connector does not provide full-database candidate reading for rediscovery.

## Before you start

Ask [Ubeeo customer support](https://ubeeo.nl/en/contact/) for the **Job feed API Token**, **Client ID**, and **Client Secret** for your organization’s integration.

Open **Integrations** in Juicebox, select **Ubeeo**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

<Note>
The screenshots show vendor settings or the connection window provided by Kombo. Use the credentials, source labels, permissions, and URLs from your own connection; screenshot values are examples.

## Enter the three credentials

Enter the job-feed token and application API client credentials in their matching fields in Juicebox and complete setup.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Export a test profile with a resume to a selected job, then verify the application in Ubeeo.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Ubeeo, follow the [export steps](/exports) and select the connected ATS and intended job.
