## About the integration

Juicebox's integration with Spark Hire Recruit allows you to:

1. **Export Profiles to Spark Hire Recruit**: Save profiles directly into Spark Hire Recruit, including contact details, current company and job, profile URLs, and more.
   1. **[Configurable] Auto-Export:** Juicebox has the ability to auto-export profiles to your ATS with configurable triggers, including after shortlisting, after adding to a sequence, or after an interested response.
   2. **Custom Integration Fields:** On some plans, integration fields can be customized further based on your preferred fields.
2. **Link Spark Hire Recruit Jobs to Juicebox**
   1. **Import Job Descriptions**: Import a job description from Spark Hire Recruit into Juicebox to automatically kick off a search using the job description.
   2. **Simplify Exports:** When exporting a profile from Juicebox to the ATS, it will automatically be connected to the correct job in the ATS. More details [here](/projects).
3. **View Profiles in Spark Hire Recruit**: View profiles already in Spark Hire Recruit within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Spark Hire Recruit integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Spark Hire Recruit jobs and can select the corresponding option.

### Export profiles to Spark Hire Recruit

Follow the regular [export](/exports) steps and select **Export to Spark Hire Recruit** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Spark Hire Recruit account.

### View profiles already in Spark Hire Recruit

Juicebox will tag profiles that already exist in Spark Hire Recruit. You will see the last modified date, as well as the option to view the profile directly in Spark Hire Recruit by clicking the **View in ATS** button.

## Before you start

Ensure you are a Spark Hire Recruit user with the **Admin** or **Owner** role.

## Copy the API key

1. In your Spark Hire Recruit dashboard, click your **profile** and go to the **settings**.

   <Frame>
     ![Settings under the profile in Spark Hire Recruit](/images/help/ats-setup/spark-hire-recruit-1.png)
   </Frame>

2. Go to **Integrations**.

   <Frame>
     ![Integrations section in settings](/images/help/ats-setup/spark-hire-recruit-2.png)
   </Frame>

3. Scroll down to **Sourcing Tools**, search for the integration, and click **Integrate**.

   <Frame>
     ![Integrate button under Sourcing Tools](/images/help/ats-setup/spark-hire-recruit-3.png)
   </Frame>

4. Click **Allow access**.

   <Frame>
     ![Allow access button](/images/help/ats-setup/spark-hire-recruit-4.png)
   </Frame>

5. Click **Copy API key** and click **Save**.

   <Frame>
     ![Copy API key and Save buttons](/images/help/ats-setup/spark-hire-recruit-5.png)
   </Frame>

6. Paste the API key into the connection pop-up.

   <Frame>
     ![Pasting the API key into the connection flow](/images/help/ats-setup/spark-hire-recruit-6.png)
   </Frame>

## Setting up the integration

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Spark Hire Recruit** and click **Activate**. You can also use the search bar at the top.
3. Follow the instructions in the connection pop-up, pasting your API key when prompted.
4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Spark Hire Recruit and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Spark Hire Recruit.
</Note>
