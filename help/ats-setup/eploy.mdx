## About the integration

The Eploy and Juicebox integration is designed to seamlessly connect both systems in a two-way sync. You can use the integration for three use cases:

1. **Import Project from ATS**: Import a job description from Eploy into Juicebox to automatically kick off a search using the job description. This also includes linking your Juicebox project to an ATS job, which makes exporting profiles to your ATS easier. More details [here](/projects).
2. **Export Profiles to ATS**: Save profiles directly into Eploy, including contact details, current company and job, profile URLs, and more. On some plans, this can be customized further based on your preferred fields. Juicebox also has the ability to auto-export to your ATS, including exporting all shortlisted profiles or exporting only interested profiles.
3. **Import Candidates**: View profiles already in Eploy within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Eploy integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Eploy jobs and can select the corresponding option.

### Export profiles to Eploy

Follow the regular [export](/exports) steps and select **Export to Eploy** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Eploy account.

### View profiles already in Eploy

Juicebox will tag profiles that already exist in Eploy. You will see the last modified date, as well as the option to view the profile directly in Eploy by clicking the **View in ATS** button.

## Set up an API user

To allow access to the Eploy API, you need to create a special user account that has access to the API.

1. In Eploy, go to **Admin** > **Users**. Here you see all users you can manage.

   <Frame>
     ![Users page under Admin in Eploy](/images/help/ats-setup/eploy-1.png)
   </Frame>

2. Click **New** > **User** to create a new standard user.

   <Frame>
     ![Creating a new user in Eploy](/images/help/ats-setup/eploy-2.png)
   </Frame>

3. On the form, complete the following fields:
   - **User Display Name**: Use a unique name that describes the user, for example "API User".
   - **User Name**: Use a unique name for your API user.
   - **Roles**: Assign exactly one role to the user. Only one role may be assigned to an API user, and the role's permissions determine which fields and data the API can access.
   - **System Email Address**, **Email Display Name**, and **Your Direct / Internal Email Address**: Use a generic email address that is not used by any real users, for example `noreply@yourcompany.com`.

Before saving the user, set up IP restrictions as described in the next section.

## Assign IP restrictions

For the user to be able to access the API, specify at least one IP range in the **Restricted IP Access** section.

1. Click the **Add** button in the Restricted IP Access section.

   <Frame>
     ![Add button in the Restricted IP Access section](/images/help/ats-setup/eploy-3.png)
   </Frame>

2. Enter `0.0.0.0/0` and click **Save** to allow access from any IPv4 source.

   <Frame>
     ![Entering the IPv4 range](/images/help/ats-setup/eploy-4.png)
   </Frame>

3. Click **Add** a second time, enter `::/0` to allow access from any IPv6 source, then click **Save**.

   <Frame>
     ![Entering the IPv6 range](/images/help/ats-setup/eploy-5.png)
   </Frame>

   <Frame>
     ![Both IP ranges added to Restricted IP Access](/images/help/ats-setup/eploy-6.png)
   </Frame>

4. Click **Save** at the bottom of the page to create the API user.

## Find your subdomain

The subdomain is the first part of the URL you use to log in to your Eploy account, the word right before `.eploy.net`. For example, if your login URL is `https://acme.eploy.net`, your subdomain is "acme".

<Frame>
  ![Finding the subdomain in the Eploy login URL](/images/help/ats-setup/eploy-7.jpg)
</Frame>

Enter the subdomain in the connection pop-up and click **Continue**.

<Frame>
  ![Entering the subdomain in the connection flow](/images/help/ats-setup/eploy-8.png)
</Frame>

## Create an API key

1. In Eploy, go to **Admin** > **Security Settings** > **API Keys**.

   <Frame>
     ![API Keys section under Security Settings](/images/help/ats-setup/eploy-9.png)
   </Frame>

2. In the API Keys section, click the **New** > **REST API** menu link.

   <Frame>
     ![New REST API menu link](/images/help/ats-setup/eploy-10.png)
   </Frame>

3. On the Create API Key page, enter a name for your API key, select the user you created earlier, and click **Save**.

   <Frame>
     ![Creating the API key and selecting the API user](/images/help/ats-setup/eploy-11.png)
   </Frame>

## Add API permissions

The connection pop-up lists the permissions the integration needs.

<Frame>
  ![Permission list shown in the connection flow](/images/help/ats-setup/eploy-12.png)
</Frame>

For each permission, repeat the following process:

1. Click the **Add** button under **API Permissions**.

   <Frame>
     ![Add button under API Permissions](/images/help/ats-setup/eploy-13.png)
   </Frame>

2. Select a permission type in the **API** dialog.

   <Frame>
     ![Selecting a permission type in the API dialog](/images/help/ats-setup/eploy-14.png)
   </Frame>

3. Check the permission boxes as required, then save.

   <Frame>
     ![Checking the permission boxes](/images/help/ats-setup/eploy-15.png)
   </Frame>

After all the permissions have been added, double-check that they match what is listed in the connection pop-up.

<Frame>
  ![Reviewing all added permissions](/images/help/ats-setup/eploy-16.png)
</Frame>

Click the save button to save the API key.

<Frame>
  ![Saving the API key](/images/help/ats-setup/eploy-17.png)
</Frame>

## Setting up the integration

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Eploy** and click **Activate**. You can also use the search bar at the top.
3. Follow the instructions in the connection pop-up, entering your subdomain, Client ID, and Client Secret when prompted, then click **Set up integration**.
4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Eploy and Juicebox.

<Note>
  If you receive an error about missing permissions despite configuring your key correctly, the user who owns the key likely does not have the appropriate permissions. The user owning the key must have at least the same permissions as the key.
</Note>

<Note>
  It may take a few minutes for all data to sync between Juicebox and Eploy.
</Note>
