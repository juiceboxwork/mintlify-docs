## About the integration

Juicebox's integration with Eightfold allows you to:

1. **Export Profiles to Eightfold**: Save profiles directly into Eightfold, including contact details, current company and job, profile URLs, and more.
   1. **[Configurable] Auto-Export:** Juicebox has the ability to auto-export profiles to your ATS with configurable triggers, including after shortlisting, after adding to a sequence, or after an interested response.
   2. **Custom Integration Fields:** On some plans, integration fields can be customized further based on your preferred fields.
2. **Link Eightfold Jobs to Juicebox**
   1. **Import Job Descriptions**: Import a job description from Eightfold into Juicebox to automatically kick off a search using the job description.
   2. **Simplify Exports:** When exporting a profile from Juicebox to the ATS, it will automatically be connected to the correct job in the ATS. More details [here](/projects).
3. **View Profiles in Eightfold**: View profiles already in Eightfold within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Eightfold integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Eightfold jobs and can select the corresponding option.

### Export profiles to Eightfold

Follow the regular [export](/exports) steps and select **Export to Eightfold** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Eightfold account.

### View profiles already in Eightfold

Juicebox will tag profiles that already exist in Eightfold. You will see the last modified date, as well as the option to view the profile directly in Eightfold by clicking the **View in ATS** button.

## Setting up the integration

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Eightfold** and click **Activate**. You can also use the search bar at the top.
3. In the connection pop-up, choose your **Eightfold API** region. If you are unsure which region to enter here, contact your Eightfold administrator.

   <Frame>
     ![Choosing the Eightfold API region in the connection pop-up](/images/help/ats-setup/eightfold-1.png)
   </Frame>

4. Log in to your Eightfold dashboard and go to the **Admin Console**. If you don't see this option, contact your systems administrator.

   <Frame>
     ![Admin Console in Eightfold](/images/help/ats-setup/eightfold-2.png)
   </Frame>

5. Go to the **Eightfold API** section.

   <Frame>
     ![Eightfold API section in the Admin Console](/images/help/ats-setup/eightfold-3.png)
   </Frame>

6. In the **Eightfold API** section, press the **Generate API Key** button.

   <Frame>
     ![Generate API Key button](/images/help/ats-setup/eightfold-4.png)
   </Frame>

7. Enter a name for your API key.

   <Frame>
     ![Naming the API key](/images/help/ats-setup/eightfold-5.png)
   </Frame>

8. Select the scopes requested in the connection pop-up.

   <Frame>
     ![Selecting the requested scopes](/images/help/ats-setup/eightfold-6.png)
   </Frame>

9. Copy the **Username** and **Password** under the OAuth 2.0 section and paste them into the connection pop-up.

   <Frame>
     ![Username and Password under the OAuth 2.0 section](/images/help/ats-setup/eightfold-7.png)
   </Frame>

   <Frame>
     ![Pasting the credentials into the connection pop-up](/images/help/ats-setup/eightfold-8.png)
   </Frame>

10. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Eightfold and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Eightfold.
</Note>
