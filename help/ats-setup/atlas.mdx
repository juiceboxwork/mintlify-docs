## About the integration

Connect Atlas to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

An Atlas administrator must create the API key. Choose the Atlas user who will own the key and be associated with candidates created by the integration.

Open **Integrations** in Juicebox, select **Atlas**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Create an API key

1. In Atlas, open **Settings > Company settings > Developers > API keys**.
2. Create a key named **Juicebox** and select its owner.
3. Match the permissions to the scope list in your Juicebox connection window, including write access where requested.
4. Create and copy the key. If scope changes do not take effect later, create a replacement key with the correct scope.

## Set the key and candidate-creation user

Enter the API key in Juicebox. When asked for a default user email for created people, enter the email of the Atlas user selected as the key owner.

## Configure webhooks when prompted

1. Copy the webhook endpoint from Juicebox.
2. In Atlas developer settings, open **Webhooks**, select **Add Endpoint**, and paste the endpoint.
3. Subscribe to the events listed in your connection window and create the endpoint.
4. Reveal and copy its signing secret, paste it into the requested field in Juicebox, and complete setup.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in Atlas.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Limitations

An existing person with the same email, phone, or LinkedIn is reused without updating the profile. Closed or on-hold projects reject writes. Attachments are stored on the person.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Atlas, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
