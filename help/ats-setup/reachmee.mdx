## About the integration

Connect ReachMee to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Request credentials from [ReachMee / Talentech support](https://talentech-support.freshdesk.com/en/support/tickets/new). Include the personalized scope list from your Juicebox connection window. API access may involve a fee.

Open **Integrations** in Juicebox, select **ReachMee**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Request credentials and publishing-place access

Ask support to provide a **Client ID** and **Client Secret** with the requested scopes, and confirm the **publishing place ID** for the jobs you intend to share.

## Enter credentials and publishing place

Enter the issued Client ID and Client Secret in Juicebox. Then supply the publishing place ID.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in ReachMee.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to ReachMee, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
