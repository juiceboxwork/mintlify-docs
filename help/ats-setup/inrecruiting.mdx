## About the integration

Connect InRecruiting by Zucchetti to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Request the integration’s **Client ID** and **Client Secret** from [InRecruiting support](https://www.in-recruiting.com/en/contact-us/). API access may involve a fee.

Open **Integrations** in Juicebox, select **InRecruiting by Zucchetti**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Retrieve the vacancies URL

1. In InRecruiting, open **System Settings** using the upper-right gear.
2. Select **Webpage Integration Options > Integrate Vacancies via JSON**.
3. Copy the complete URL under **Get Code**, including all query parameters.
4. Paste that full URL into Juicebox and complete setup.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in InRecruiting by Zucchetti.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to InRecruiting by Zucchetti, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
