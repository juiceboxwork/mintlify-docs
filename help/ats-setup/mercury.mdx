## About the integration

Juicebox's integration with Mercury allows you to:

1. **Export Profiles to Mercury**: Save profiles directly into Mercury, including contact details, current company and job, profile URLs, and more.
   1. **[Configurable] Auto-Export:** Juicebox has the ability to auto-export profiles to your ATS with configurable triggers, including after shortlisting, after adding to a sequence, or after an interested response.
   2. **Custom Integration Fields:** On some plans, integration fields can be customized further based on your preferred fields.
2. **Link Mercury Jobs to Juicebox**
   1. **Import Job Descriptions**: Import a job description from Mercury into Juicebox to automatically kick off a search using the job description.
   2. **Simplify Exports:** When exporting a profile from Juicebox to the ATS, it will automatically be connected to the correct job in the ATS. More details [here](/projects).
3. **View Profiles in Mercury**: View profiles already in Mercury within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Mercury integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Mercury jobs and can select the corresponding option.

### Export profiles to Mercury

Follow the regular [export](/exports) steps and select **Export to Mercury** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Mercury account.

### View profiles already in Mercury

Juicebox will tag profiles that already exist in Mercury. You will see the last modified date, as well as the option to view the profile directly in Mercury by clicking the **View in ATS** button.

## Get your tenant ID

Before setting up this integration, contact your Mercury Customer Success Manager (CSM) to authorize API access. The CSM raises an internal request and, once approved, provides you with a **Tenant ID**.

<Note>
  Even if you already know your Tenant ID, the connection fails until Mercury has explicitly granted access.
</Note>

You can use this email template:

> **Subject:** Mercury Tenant ID Request - [Your Company Name]
>
> Hi Mercury team,
>
> We are setting up an integration with our Mercury account. As part of this process, we need the Mercury Tenant ID.
>
> Could you please provide us with our Tenant ID and authorize this connection on your side so we can complete the setup?
>
> Thank you!
>
> Best regards,

## Setting up the integration

Before getting started, make sure that you have your **Tenant ID**.

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Mercury** and click **Activate**. You can also use the search bar at the top.
3. Enter the **Tenant ID** and press **Set up integration**.

   <Frame>
     ![Entering the Tenant ID in the connection flow](/images/help/ats-setup/mercury-1.png)
   </Frame>

4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Mercury and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Mercury.
</Note>
