## About the integration

Juicebox's integration with Workable allows you to:

1. **Export Profiles to Workable**: Save profiles directly into Workable, including contact details, current company and job, profile URLs, and more.
   1. **[Configurable] Auto-Export:** Juicebox has the ability to auto-export profiles to your ATS with configurable triggers, including after shortlisting, after adding to a sequence, or after an interested response.
   2. **Custom Integration Fields:** On some plans, integration fields can be customized further based on your preferred fields.
2. **Link Workable Jobs to Juicebox**
   1. **Import Job Descriptions**: Import a job description from Workable into Juicebox to automatically kick off a search using the job description.
   2. **Simplify Exports:** When exporting a profile from Juicebox to the ATS, it will automatically be connected to the correct job in the ATS. More details [here](/projects).
3. **View Profiles in Workable**: View profiles already in Workable within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Workable integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Workable jobs and can select the corresponding option.

### Export profiles to Workable

Follow the regular [export](/exports) steps and select **Export to Workable** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Workable account.

### View profiles already in Workable

Juicebox will tag profiles that already exist in Workable. You will see the last modified date, as well as the option to view the profile directly in Workable by clicking the **View in ATS** button.

## Before you start

You need an account in your company's Workable instance, or someone must share their access with you.

## Find your subdomain

1. Log in to Workable, open the dropdown menu on the top right of your screen, and select **Settings**.

   <Frame>
     ![Settings option in the Workable dropdown menu](/images/help/ats-setup/workable-1.png)
   </Frame>

2. Click **Company profile** in the menu bar on the left side of the screen. You can find your subdomain under **Subdomain** on the company profile settings page.

   <Frame>
     ![Subdomain on the company profile settings page](/images/help/ats-setup/workable-2.png)
   </Frame>

## Get the API token

1. Log in to Workable, open the dropdown menu on the top right of your screen, and select **Settings**.

   <Frame>
     ![Settings option in the Workable dropdown menu](/images/help/ats-setup/workable-1.png)
   </Frame>

2. Click **Apps** in the menu bar on the left side of the screen.

   <Frame>
     ![Apps option in the left menu bar](/images/help/ats-setup/workable-3.png)
   </Frame>

3. Click the **Generate API token** button under the **API Access Tokens** section.

   <Frame>
     ![Generate API token button under API Access Tokens](/images/help/ats-setup/workable-4.png)
   </Frame>

4. Choose a name and expiration date, and add permissions to your API key. Then click **Generate Token**.

   <Frame>
     ![Choosing a name, expiration date, and permissions for the token](/images/help/ats-setup/workable-5.png)
   </Frame>

5. Once you click the generate button, the new access token appears.

   <Frame>
     ![Newly generated access token](/images/help/ats-setup/workable-6.png)
   </Frame>

6. Copy your API key. You paste it into the connection pop-up later, which validates the key and prompts you with the remaining steps.

   <Frame>
     ![Pasting the API key into the connection flow](/images/help/ats-setup/workable-7.png)
   </Frame>

## Set up an external recruiter

1. Click the profile circle in the top right corner, then click **Settings**.

   <Frame>
     ![Settings under the profile circle](/images/help/ats-setup/workable-8.png)
   </Frame>

2. Click **Account members** in the left sidebar.

   <Frame>
     ![Account members option in the left sidebar](/images/help/ats-setup/workable-9.png)
   </Frame>

3. Click **Add an external recruiter**.

   <Frame>
     ![Add an external recruiter button](/images/help/ats-setup/workable-10.png)
   </Frame>

4. For the recruiter's **Name** and **Email**, copy the values provided in the connection pop-up.

   <Frame>
     ![Name and email values provided in the connection flow](/images/help/ats-setup/workable-11.png)
   </Frame>

5. Enter the values you copied, then click **Add recruiter**.

   <Frame>
     ![Adding the external recruiter](/images/help/ats-setup/workable-12.png)
   </Frame>

## Setting up the integration

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Workable** and click **Activate**. You can also use the search bar at the top.
3. Follow the instructions in the connection pop-up, entering your subdomain and API token, and adding the external recruiter when prompted.
4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Workable and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Workable.
</Note>
