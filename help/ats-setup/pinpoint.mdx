## About the integration

The Pinpoint and Juicebox integration is designed to seamlessly connect both systems in a two-way sync. You can use the integration for three use cases:

1. **Import Project from ATS**: Import a job description from Pinpoint into Juicebox to automatically kick off a search using the job description. This also includes linking your Juicebox project to an ATS job, which makes exporting profiles to your ATS easier. More details [here](/projects).
2. **Export Profiles to ATS**: Save profiles directly into Pinpoint, including contact details, current company and job, profile URLs, and more. On some plans, this can be customized further based on your preferred fields. Juicebox also has the ability to auto-export to your ATS, including exporting all shortlisted profiles or exporting only interested profiles.
3. **Import Candidates**: View profiles already in Pinpoint within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Pinpoint integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Pinpoint jobs and can select the corresponding option.

### Export profiles to Pinpoint

Follow the regular [export](/exports) steps and select **Export to Pinpoint** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Pinpoint account.

### View profiles already in Pinpoint

Juicebox will tag profiles that already exist in Pinpoint. You will see the last modified date, as well as the option to view the profile directly in Pinpoint by clicking the **View in ATS** button.

## Before you start

Your account must belong to the **Administrator** access group in your company's Pinpoint instance.

1. Log in to Pinpoint and navigate to the sidebar on the left side of the screen.

   <Frame>
     ![Sidebar on the left side of Pinpoint](/images/help/ats-setup/pinpoint-1.png)
   </Frame>

2. If you cannot see the **Settings** option on the sidebar, your account does not belong to the **Administrator** access group. Find out who is in the Administrator access group in your company's Pinpoint instance, and ask them to promote you or take over the setup process.

## Create an API key in Pinpoint

1. Log in to Pinpoint.
2. Navigate to the sidebar on the left side of the screen and click **API & Webhooks** under the **Settings** section.

   <Frame>
     ![API and Webhooks under the Settings section](/images/help/ats-setup/pinpoint-1.png)
   </Frame>

3. In the **API Keys** tab, make sure the **Pinpoint API** toggle is enabled and click **CREATE NEW**.

   <Frame>
     ![Pinpoint API toggle and CREATE NEW button](/images/help/ats-setup/pinpoint-2.png)
   </Frame>

4. Enter a name for the key.

   <Frame>
     ![Naming the API key](/images/help/ats-setup/pinpoint-3.png)
   </Frame>

5. Select the permissions as shown in the connection pop-up.

   <Frame>
     ![Selecting the permissions shown in the connection flow](/images/help/ats-setup/pinpoint-4.png)
   </Frame>

6. Scroll down to the bottom of the tab and click **CREATE API KEY**.

   <Frame>
     ![CREATE API KEY button](/images/help/ats-setup/pinpoint-5.png)
   </Frame>

7. Click the copy icon to copy your newly created API key.

   <Frame>
     ![Copying the newly created API key](/images/help/ats-setup/pinpoint-6.png)
   </Frame>

8. Paste the copied key into the connection pop-up.

   <Frame>
     ![Pasting the API key into the connection flow](/images/help/ats-setup/pinpoint-7.png)
   </Frame>

## Setting up the integration

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Pinpoint** and click **Activate**. You can also use the search bar at the top.
3. Follow the instructions in the connection pop-up, pasting your API key when prompted.
4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Pinpoint and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Pinpoint.
</Note>
