## About the integration

Juicebox's integration with Loxo allows you to:

1. **Export Profiles to Loxo**: Save profiles directly into Loxo, including contact details, current company and job, profile URLs, and more.
   1. **[Configurable] Auto-Export:** Juicebox has the ability to auto-export profiles to your ATS with configurable triggers, including after shortlisting, after adding to a sequence, or after an interested response.
   2. **Custom Integration Fields:** On some plans, integration fields can be customized further based on your preferred fields.
2. **Link Loxo Jobs to Juicebox**
   1. **Import Job Descriptions**: Import a job description from Loxo into Juicebox to automatically kick off a search using the job description.
   2. **Simplify Exports:** When exporting a profile from Juicebox to the ATS, it will automatically be connected to the correct job in the ATS. More details [here](/projects).
3. **View Profiles in Loxo**: View profiles already in Loxo within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Loxo integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Loxo jobs and can select the corresponding option.

### Export profiles to Loxo

Follow the regular [export](/exports) steps and select **Export to Loxo** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Loxo account.

### View profiles already in Loxo

Juicebox will tag profiles that already exist in Loxo. You will see the last modified date, as well as the option to view the profile directly in Loxo by clicking the **View in ATS** button.

## Create an API key

1. In Loxo, click your account name in the bottom left corner, then click **Settings**.

   <Frame>
     ![Settings in the Loxo account menu](/images/help/ats-setup/loxo-1.png)
   </Frame>

2. Scroll down to **Workspace**, then click **API Keys**.

   <Frame>
     ![API Keys under Workspace settings](/images/help/ats-setup/loxo-2.png)
   </Frame>

3. In the top right, click **+ Add**.

   <Frame>
     ![Add button on the API Keys page](/images/help/ats-setup/loxo-3.png)
   </Frame>

4. Copy the created API key.

   <Frame>
     ![Copying the created API key](/images/help/ats-setup/loxo-4.png)
   </Frame>

## Connect Loxo to Juicebox

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Loxo** and click **Activate**. You can also use the search bar at the top.
3. Paste the API key into the connection pop-up.
4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Loxo and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Loxo.
</Note>
