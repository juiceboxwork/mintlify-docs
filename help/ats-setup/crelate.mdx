## About the integration

The Crelate and Juicebox integration is designed to seamlessly connect both systems in a two-way sync. You can use the integration for three use cases:

1. **Import Project from ATS**: Import a job description from Crelate into Juicebox to automatically kick off a search using the job description. This also includes linking your Juicebox project to an ATS job, which makes exporting profiles to your ATS easier. More details [here](/projects).
2. **Export Profiles to ATS**: Save profiles directly into Crelate, including contact details, current company and job, profile URLs, and more. On some plans, this can be customized further based on your preferred fields. Juicebox also has the ability to auto-export to your ATS, including exporting all shortlisted profiles or exporting only interested profiles.
3. **Import Candidates**: View profiles already in Crelate within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Crelate integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Crelate jobs and can select the corresponding option.

### Export profiles to Crelate

Follow the regular [export](/exports) steps and select **Export to Crelate** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Crelate account.

### View profiles already in Crelate

Juicebox will tag profiles that already exist in Crelate. You will see the last modified date, as well as the option to view the profile directly in Crelate by clicking the **View in ATS** button.

## Create an API key

1. Log in to Crelate.
2. Click the **Menu** icon in the top left of the page.

   <Frame>
     ![Menu icon in Crelate](/images/help/ats-setup/crelate-1.png)
   </Frame>

3. Click **Manage Your Profile & Preferences** in the dropdown.

   <Frame>
     ![Manage Your Profile & Preferences in the dropdown](/images/help/ats-setup/crelate-2.png)
   </Frame>

4. Click **API Access** under **PERSONAL SETTINGS**.

   <Frame>
     ![API Access under personal settings](/images/help/ats-setup/crelate-3.png)
   </Frame>

5. Make sure **Enable API Access** is set to **On**, and copy the API key.

   <Frame>
     ![Enable API Access toggle and API key](/images/help/ats-setup/crelate-4.png)
   </Frame>

## Connect Crelate to Juicebox

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Crelate** and click **Activate**. You can also use the search bar at the top.
3. In the connection pop-up, paste the API key and press **Set up integration**.

   <Frame>
     ![Pasting the API key in the connection pop-up](/images/help/ats-setup/crelate-5.png)
   </Frame>

4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Crelate and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Crelate.
</Note>
