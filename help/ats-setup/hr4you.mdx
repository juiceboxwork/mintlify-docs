## About the integration

Connect HR4YOU to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Ask your HR4YOU representative to enable the API. API access may be paid. An HR4YOU administrator must create the integration user and arrange its API assignment.

Open **Integrations** in Juicebox, select **HR4YOU**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Create and enable the API user

1. Create a new HR4YOU user.
2. Set its level to **Berater** and select the appropriate user group.
3. Fill in the required fields, set **Zugangsstatus** to **Aktiv**, and select **Geschäftsführer** under **Rolle (Zugriffsrechte)**, as required by the documented connection procedure.
4. Select **Registrieren** and enter the user credentials in the connection window.

## Ask HR4YOU to assign API access

Contact your HR4YOU representative to assign the new user to the API. This assignment must be performed by HR4YOU. After they confirm it, complete the connection in Juicebox.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in HR4YOU.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to HR4YOU, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
