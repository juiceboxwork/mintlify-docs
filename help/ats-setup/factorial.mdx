## About the integration

Connect Factorial to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

The authorizing account must belong to Factorial’s **Administrators** permission group. In Settings, it should be able to see **Advanced configuration > API Keys**.

Open **Integrations** in Juicebox, select **Factorial**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Authorize Factorial

1. In the Juicebox connection window, select **Sign in with Factorial**.
2. Sign in with the administrator account and approve the requested access.
3. Complete the authorization and return to Juicebox.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in Factorial.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Factorial, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
