## About the integration

Connect Cornerstone OnDemand to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Have a Cornerstone administrator available and identify the subdomain for your portal. This is the OnDemand connector, separate from Cornerstone TalentLink.

Open **Integrations** in Juicebox, select **Cornerstone OnDemand**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

The screenshots show vendor settings or the connection window provided by Kombo. Use the credentials, source labels, permissions, and URLs from your own connection; screenshot values are examples.

## Register the API application

1. Enter your Cornerstone OnDemand subdomain in Juicebox.
2. In Cornerstone, open **Admin > Tools > Edge > API Management**.
3. On **Manage Applications**, choose **Register New Application**.
4. Enter an application name and the ID of an active portal user. Leave **Access Token Validity Period** empty.
5. Add the scopes shown in your current Juicebox connection window and register the application.

## Enter the client credentials

Copy the registered application’s **Client ID** and **Client Secret** into Juicebox and complete setup.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in Cornerstone OnDemand.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Limitations

Each application supports at most one CV and one cover letter. Candidate creation can take up to five minutes.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Cornerstone OnDemand, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
