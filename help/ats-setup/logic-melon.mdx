## About the integration

Connect Logic Melon to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Ask your Logic Melon account manager or support team to enable **Multiposter API access** and provide an **API key**, **username**, and **password** for the integration.

Open **Integrations** in Juicebox, select **Logic Melon**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Connect with the Multiposter credentials

Enter all three credentials in the Juicebox connection window and select **Set up integration**.

## Confirm the history range

Kombo defaults to reading the last 365 days. If older candidates or applications are needed, ask Juicebox Support to configure the date range before relying on rediscovery results.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in Logic Melon.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Limitations

The default history window is 365 days. Only one attachment is submitted, preferring the CV.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Logic Melon, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
