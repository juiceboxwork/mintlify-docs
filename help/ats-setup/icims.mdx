## About the integration

Juicebox's integration with iCIMS allows you to:

1. **Export Profiles to iCIMS**: Save profiles directly into iCIMS, including contact details, current company and job, profile URLs, and more.
   1. **[Configurable] Auto-Export:** Juicebox has the ability to auto-export profiles to your ATS with configurable triggers, including after shortlisting, after adding to a sequence, or after an interested response.
   2. **Custom Integration Fields:** On some plans, integration fields can be customized further based on your preferred fields.
2. **Link iCIMS Jobs to Juicebox**
   1. **Import Job Descriptions**: Import a job description from iCIMS into Juicebox to automatically kick off a search using the job description.
   2. **Simplify Exports:** When exporting a profile from Juicebox to the ATS, it will automatically be connected to the correct job in the ATS. More details [here](/projects).
3. **View Profiles in iCIMS**: View profiles already in iCIMS within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the iCIMS integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your iCIMS jobs and can select the corresponding option.

### Export profiles to iCIMS

Follow the regular [export](/exports) steps and select **Export to iCIMS** on either an individual profile or a bulk export. After exporting, you will see the profile created in your iCIMS account.

### View profiles already in iCIMS

Juicebox will tag profiles that already exist in iCIMS. You will see the last modified date, as well as the option to view the profile directly in iCIMS by clicking the **View in ATS** button.

## Receive your credentials from iCIMS

iCIMS requires an integration project before it issues API credentials. To integrate with iCIMS, complete the following process:

1. Sign a SOW (statement of work) for the integration project. The time from signing the SOW to kicking off the integration project is usually 6-8 weeks.
2. Pay the integration project fee. iCIMS doesn't disclose the usual amount they charge for such projects.
3. Join an integration scoping call between you, iCIMS support, and the service provider. On this call, iCIMS will want to understand the use case and the requirements on both sides.

To kick off the process, reach out to your iCIMS Customer Support Manager to set up the scoping call.

After those steps are completed, iCIMS provides you with the credentials you need for the connection flow:

- Customer ID
- iCIMS Server region
- API Client ID
- API Client Secret

## Setting up the integration

Once you have received the credentials from your iCIMS support contact, connect your account:

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **iCIMS** and click **Activate**. You can also use the search bar at the top.
3. In the connection pop-up, enter your **Customer ID** and select your **iCIMS Region**, then click **Continue**.

   <Frame>
     ![Entering the iCIMS Customer ID and selecting the region in the connection flow](/images/help/ats-setup/icims-1.png)
   </Frame>

4. Enter your API **Client ID** and API **Client Secret**, and click **Set up integration**.

   <Frame>
     ![Entering the API Client ID and Client Secret in the connection flow](/images/help/ats-setup/icims-2.png)
   </Frame>

5. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated iCIMS and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and iCIMS.
</Note>
