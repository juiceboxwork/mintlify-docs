## About the integration

Connect TrackerRMS to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Use an account with access to **Tools & Settings**. Check your login URL for the hosting region: `evous` means United States, `evoca` means Canada, and `evogl` means Rest of world.

Open **Integrations** in Juicebox, select **TrackerRMS**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Retrieve an access token

Open your user menu, then **Tools & Settings > Security > Security Settings**. In the **API** section, copy the existing access token, or generate one if there is none. Generating a replacement invalidates the previous token, so coordinate that change if other integrations use it.

## Connect the correct region

Select the region matching your TrackerRMS login URL, enter the Access Token, and select **Set up integration**. If validation fails, check the region and full token before considering token replacement.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in TrackerRMS.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to TrackerRMS, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
