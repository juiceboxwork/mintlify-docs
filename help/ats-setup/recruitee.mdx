## About the integration

The Recruitee and Juicebox integration is designed to seamlessly connect both systems in a two-way sync. You can use the integration for three use cases:

1. **Import Project from ATS**: Import a job description from Recruitee into Juicebox to automatically kick off a search using the job description. This also includes linking your Juicebox project to an ATS job, which makes exporting profiles to your ATS easier. More details [here](/projects).
2. **Export Profiles to ATS**: Save profiles directly into Recruitee, including contact details, current company and job, profile URLs, and more. On some plans, this can be customized further based on your preferred fields. Juicebox also has the ability to auto-export to your ATS, including exporting all shortlisted profiles or exporting only interested profiles.
3. **Import Candidates**: View profiles already in Recruitee within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Recruitee integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Recruitee jobs and can select the corresponding option.

### Export profiles to Recruitee

Follow the regular [export](/exports) steps and select **Export to Recruitee** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Recruitee account.

### View profiles already in Recruitee

Juicebox will tag profiles that already exist in Recruitee. You will see the last modified date, as well as the option to view the profile directly in Recruitee by clicking the **View in ATS** button.

## Before you start

You must be an administrator of your Recruitee instance, or an admin must ensure your hiring role has sufficient permissions.

To verify that you are an administrator:

1. Click your profile picture in the top right corner.

     ![Profile picture in the top right corner of Recruitee](/images/help/ats-setup/recruitee-1.png)
   </Frame>

2. Check that you see **Administrator** below your name.

   <Frame>

## Configure a hiring role (admins only)

If you are the administrator of your Recruitee account and want to enable another user to set up the integration, update the permissions of that user's hiring role to match the permissions listed in the connection pop-up.

1. Click the cog icon in the top right corner.

   <Frame>
     ![Cog icon in the top right corner of Recruitee](/images/help/ats-setup/recruitee-3.png)
   </Frame>

2. In the sidebar under **Company**, click **Hiring roles**.

   <Frame>
     ![Hiring roles option under Company in the sidebar](/images/help/ats-setup/recruitee-4.png)
   </Frame>

3. Either click **Create new role** to create a new role, or click an existing role to edit it. In either case, make sure the user who should create the API token is assigned to the role you are configuring.

   <Frame>
     ![Creating or editing a hiring role](/images/help/ats-setup/recruitee-5.png)
   </Frame>

4. Edit the role to include all the permissions listed in the connection pop-up. The screenshot below is an example of possible permissions. Reference your own connection pop-up when selecting the permissions you add to the role.

   <Frame>
     ![Example permissions on a hiring role](/images/help/ats-setup/recruitee-6.png)
   </Frame>

## Create an API token in Recruitee

1. Click the cog icon in the top right corner.

   <Frame>
     ![Cog icon in the top right corner of Recruitee](/images/help/ats-setup/recruitee-3.png)
   </Frame>

2. In the sidebar, click **Personal API tokens**.

   <Frame>
     ![Personal API tokens option in the sidebar](/images/help/ats-setup/recruitee-7.png)
   </Frame>

3. Click **New token** to create a new token.

   <Frame>
     ![New token button](/images/help/ats-setup/recruitee-8.png)
   </Frame>

   <Frame>
     ![Personal API tokens page after clicking New token](/images/help/ats-setup/recruitee-9.png)
   </Frame>

4. Give the token any name that helps you remember it.

   <Frame>
     ![Naming the new API token](/images/help/ats-setup/recruitee-10.png)
   </Frame>

5. Recruitee sends you a code via email. Paste the code and click **Continue**.

   <Frame>
     ![Entering the email verification code](/images/help/ats-setup/recruitee-11.png)
   </Frame>

6. Copy the **token** and the **company ID**. You paste both into the connection pop-up in the next section.

   <Frame>
     ![Copying the token and company ID](/images/help/ats-setup/recruitee-12.png)
   </Frame>

## Setting up the integration

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Recruitee** and click **Activate**. You can also use the search bar at the top.
3. Follow the instructions in the connection pop-up, pasting your token and company ID when prompted.
4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Recruitee and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Recruitee.
</Note>
