## About the integration

The Spott and Juicebox integration is designed to seamlessly connect both systems in a two-way sync. You can use the integration for three use cases:

1. **Import Project from ATS**: Import a job description from Spott into Juicebox to automatically kick off a search using the job description. This also includes linking your Juicebox project to an ATS job, which makes exporting profiles to your ATS easier. More details [here](/projects).
2. **Export Profiles to ATS**: Save profiles directly into Spott, including contact details, current company and job, profile URLs, and more. On some plans, this can be customized further based on your preferred fields. Juicebox also has the ability to auto-export to your ATS, including exporting all shortlisted profiles or exporting only interested profiles.
3. **Import Candidates**: View profiles already in Spott within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Spott integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Spott jobs and can select the corresponding option.

### Export profiles to Spott

Follow the regular [export](/exports) steps and select **Export to Spott** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Spott account.

### View profiles already in Spott

Juicebox will tag profiles that already exist in Spott. You will see the last modified date, as well as the option to view the profile directly in Spott by clicking the **View in ATS** button.

## Create an API key in Spott

1. Log in to your Spott dashboard at `app.gospott.com`.
2. Click the Spott logo in the top left corner.

   <Frame>
     ![Spott logo in the top left corner of the dashboard](/images/help/ats-setup/spott-1.png)
   </Frame>

3. Click **Settings**.

   <Frame>
     ![Settings option in Spott](/images/help/ats-setup/spott-2.png)
   </Frame>

4. Click **API** in the bottom left, then click **+ Create API Key**.

   <Frame>
     ![API section with the Create API Key button](/images/help/ats-setup/spott-3.png)
   </Frame>

5. Give the API key a name and click **Create Key**.

   <Frame>
     ![Naming the API key and clicking Create Key](/images/help/ats-setup/spott-4.png)
   </Frame>

6. Click **Copy key** and keep it somewhere safe. You paste it into the connection pop-up in the next section.

   <Frame>
     ![Copy key button for the generated API key](/images/help/ats-setup/spott-5.png)
   </Frame>

## Setting up the integration

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Spott** and click **Activate**. You can also use the search bar at the top.
3. Follow the instructions in the connection pop-up, pasting your API key when prompted.
4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Spott and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Spott.
</Note>
