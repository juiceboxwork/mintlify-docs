## About the integration

Connect Digital Recruiters to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

This integration is in **Closed Beta**. Confirm access with Juicebox Support first, then ask your Digital Recruiters / Cegid HR contact to provision access for your environment.

Open **Integrations** in Juicebox, select **Digital Recruiters**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Request the required credentials

Request the **job feed token**, **application feed token**, and **base URL / environment**. If you want to sync the existing candidate database, also request an **API key** and the account credentials needed for candidate export.

## Enter the job-feed details

Use the domain from your Digital Recruiters login. Enter the job-feed access token—the token at the end of `/export/job-ads/TOKEN`—in the corresponding connection field.

## Enable candidate reading if needed

If your configured scope includes all candidates, supply the API key and candidate-export account credentials when prompted. Complete any application-feed prompts using the credentials issued by Cegid HR, then finish setup.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in Digital Recruiters.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Limitations

Only one attachment is sent, preferring the CV. The vendor API does not report closed-job or duplicate-application errors, so verify the destination before repeating an export.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Digital Recruiters, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
