## Using the integration

Juicebox's integration with Ashby allows you to:

1. **Export Profiles to Ashby**: Save profiles directly into Ashby, including contact details, current company and job, profile URLs, source, and more.
   1. **[Configurable] Auto-Export:** Juicebox has the ability to auto-export profiles to your ATS with configurable triggers, including: After Shortlist, After Outreach [default], After Interested Response
   2. **Custom Integration Fields:** On some plans, integration fields can be customized further based on your preferred fields.
2. **Rediscover Talent**: Filter for and view profiles already in Ashby within Juicebox, including filtering by tags, jobs, and stage. Learn more about [Talent Rediscovery](/talent-rediscovery).
3. **Link Ashby Jobs to Juicebox**
   1. **Import Job Descriptions**: Import a job description from Ashby into Juicebox to automatically kick off a search using the job description.
   2. **Simplify Exports:** When exporting a profile from Juicebox to the ATS, it will automatically be connected to the correct job in the ATS. More details [here](/projects).
4. **View Profile in Ashby**: View profiles already in Ashby within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Ashby integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Ashby jobs and can select the corresponding option.

<Frame>
  ![Linking a new project to an Ashby job and selecting a synced job description](/images/help/ats-setup/ashby-import-job.png)
</Frame>

### Export profiles to Ashby

Follow the regular [export](/exports) steps and select **Export to Ashby** on either an individual profile or a bulk export. After exporting to Ashby, you will see the profile created in your Ashby account.

### View profiles already in Ashby

Juicebox will tag profiles that already exist in Ashby. You will see the last modified date, as well as the option to view the profile directly in Ashby by clicking the **View in ATS** button.

## Setting up the integration

1. To connect Juicebox with Ashby, open the **Integrations** tab on the left-hand side of the Juicebox platform.

   <Frame>
     ![Integrations tab highlighted in the left-hand navigation](/images/help/ats-setup/ashby-integrations-tab.png)
   </Frame>

2. Select **Ashby**, then select **Connect Ashby**. You can also use the search bar at the top.

   <Frame>
     ![Connect Ashby button on the Ashby tile in the Integrations page](/images/help/ats-setup/ashby-connect-tile.png)
   </Frame>

3. Follow the steps detailed in [this video](https://tella.video/ashby-integration-demo-2024-1-20j6):

   ![Ashby integration demo](/images/help/ats-setup/ashby-5.png)

4. Note the suggested minimum scopes below.

   ![Suggested minimum API scopes](/images/help/ats-setup/ashby-6.png)

5. After you have signed in, the window will close and you will be redirected to Juicebox. Refresh your page — if successful, you will see a green **Connected** button.

   <Frame>
     ![Ashby tile showing the green Connected status](/images/help/ats-setup/ashby-connected.png)
   </Frame>

Congratulations! You have successfully integrated Ashby and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Ashby. Wait up to 10 minutes to ensure all data has been synced.
</Note>
