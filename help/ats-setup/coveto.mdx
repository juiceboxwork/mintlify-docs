## About the integration

Connect Coveto to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Use the **Coveto REST API** connector. The publicly available Coveto connection walkthrough describes the legacy SOAP API, so its SOAP-user steps do not apply here.

## Prepare REST API access

Ask your Coveto administrator and [Juicebox Support](mailto:support@juicebox.ai) to confirm REST API availability for your account and the credentials required by the current connection flow. State explicitly that you are connecting through **Coveto REST API**, not the legacy SOAP connector.

## Connect using the current REST flow

Open the connection link supplied by Juicebox, enter the instance details and credentials requested there, and complete the prompts. Ask Support to help if your account shows SOAP-only instructions or the REST option is unavailable.

## Confirm the configured access

Verify that your expected jobs appear and that a known candidate can be found. Export a test profile with a resume to a selected job and confirm the application in Coveto.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Coveto, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
