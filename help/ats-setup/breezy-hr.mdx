## About the integration

The Breezy HR and Juicebox integration is designed to seamlessly connect both systems in a two-way sync. You can use the integration for three use cases:

1. **Import Project from ATS**: Import a job description from Breezy HR into Juicebox to automatically kick off a search using the job description. This also includes linking your Juicebox project to an ATS job, which makes exporting profiles to your ATS easier. More details [here](/projects).
2. **Export Profiles to ATS**: Save profiles directly into Breezy HR, including contact details, current company and job, profile URLs, and more. On some plans, this can be customized further based on your preferred fields. Juicebox also has the ability to auto-export to your ATS, including exporting all shortlisted profiles or exporting only interested profiles.
3. **Import Candidates**: View profiles already in Breezy HR within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Breezy HR integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Breezy HR jobs and can select the corresponding option.

### Export profiles to Breezy HR

Follow the regular [export](/exports) steps and select **Export to Breezy HR** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Breezy HR account.

### View profiles already in Breezy HR

Juicebox will tag profiles that already exist in Breezy HR. You will see the last modified date, as well as the option to view the profile directly in Breezy HR by clicking the **View in ATS** button.

## Before you start

- Your company needs to be on the **Custom Pro Plan** of Breezy HR for the Breezy HR API to be enabled. This is Breezy HR's enterprise/custom plan. Contact `support@breezyhr.com` or your account manager to enable API access if you are already on the Custom Pro Plan.
- You need to be an **Admin** in Breezy HR. If you are not an Admin, reach out to your administrator or IT department. You know you are an Admin if you can see your **Company Settings** after clicking the cog in the top left corner.

  <Frame>
    ![Company Settings visible after clicking the cog icon](/images/help/ats-setup/breezy-hr-1.png)
  </Frame>

- Recommended: create a new user for the integration in the format `integration-juicebox@your-company-domain.com`. Breezy HR uses your own login information for integrations. If the connection is set up with a personal admin login and that person leaves the company or loses admin access, the connection fails.

## Create an integration user in Breezy HR

1. Log in to Breezy HR, then click the cog in the top left corner.

   <Frame>
     ![Cog icon in the top left corner of Breezy HR](/images/help/ats-setup/breezy-hr-2.png)
   </Frame>

2. Click **Invite Members**.

   <Frame>
     ![Invite Members option](/images/help/ats-setup/breezy-hr-3.png)
   </Frame>

3. Enter the email you wish to use for the integration user, set their role to **Administrator**, and click **Invite User(s)**.

   <Frame>
     ![Inviting the integration user as an Administrator](/images/help/ats-setup/breezy-hr-4.png)
   </Frame>

4. Verify the email of the user you just created. You enter their email address and password into the connection pop-up in the next section.

   <Frame>
     ![Entering the integration user credentials into the connection flow](/images/help/ats-setup/breezy-hr-5.png)
   </Frame>

## Setting up the integration

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Breezy HR** and click **Activate**. You can also use the search bar at the top.
3. Follow the instructions in the connection pop-up, entering the integration user's email address and password when prompted.
4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Breezy HR and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Breezy HR.
</Note>
