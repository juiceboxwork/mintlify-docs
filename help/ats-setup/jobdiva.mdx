## About the integration

Juicebox's integration with JobDiva allows you to:

1. **Export Profiles to JobDiva**: Save profiles directly into JobDiva, including contact details, current company and job, profile URLs, and more.
   1. **[Configurable] Auto-Export:** Juicebox has the ability to auto-export profiles to your ATS with configurable triggers, including after shortlisting, after adding to a sequence, or after an interested response.
   2. **Custom Integration Fields:** On some plans, integration fields can be customized further based on your preferred fields.
2. **Link JobDiva Jobs to Juicebox**
   1. **Import Job Descriptions**: Import a job description from JobDiva into Juicebox to automatically kick off a search using the job description.
   2. **Simplify Exports:** When exporting a profile from Juicebox to the ATS, it will automatically be connected to the correct job in the ATS. More details [here](/projects).
3. **View Profiles in JobDiva**: View profiles already in JobDiva within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the JobDiva integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your JobDiva jobs and can select the corresponding option.

### Export profiles to JobDiva

Follow the regular [export](/exports) steps and select **Export to JobDiva** on either an individual profile or a bulk export. After exporting, you will see the profile created in your JobDiva account.

### View profiles already in JobDiva

Juicebox will tag profiles that already exist in JobDiva. You will see the last modified date, as well as the option to view the profile directly in JobDiva by clicking the **View in ATS** button.

## Get your JobDiva Client ID from JobDiva support

1. Reach out to [JobDiva Support](https://www.jobdiva.com/support) and request a Client ID for this integration.
2. Enter the Client ID in the connection pop-up.

   <Frame>
     ![Entering the Client ID in the connection flow](/images/help/ats-setup/jobdiva-1.png)
   </Frame>

## Set up an API user

1. Log in to your JobDiva portal.
2. Navigate to **Settings** > **My Team** > **Add User**.
3. Add a new user. Make sure to select the **Only allow to access JobDiva API Calls** permission for the user.
4. Enter the API user's username and password into the connection pop-up.

   <Frame>
     ![Entering the API user's username and password in the connection flow](/images/help/ats-setup/jobdiva-2.png)
   </Frame>

## Setting up the integration

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **JobDiva** and click **Activate**. You can also use the search bar at the top.
3. Follow the instructions in the connection pop-up, entering the Client ID and the API user's credentials from the sections above.
4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated JobDiva and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and JobDiva.
</Note>
