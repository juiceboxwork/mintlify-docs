## About the integration

Connect HR Office to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. This connector does not provide full-database candidate reading for rediscovery.

## Before you start

Ask your HROffice customer success manager to create an **API career site** for your Juicebox integration. Wait for confirmation before retrieving its credentials.

Open **Integrations** in Juicebox, select **HR Office**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

<Note>
The screenshots show vendor settings or the connection window provided by Kombo. Use the credentials, source labels, permissions, and URLs from your own connection; screenshot values are examples.
</Note>

## Find the API career site

Open [Career site settings](https://portal.hroffice.eu/settings/sites), or go to **Settings > Career Sites > Configuration**. Edit the career site whose type is **API**.

## Copy the credentials and connect

Copy the **Portal ID** and **API Key** from that site, enter them in Juicebox, and finish setup.

<Frame caption="Use the Portal ID and API key from the API career site.">
  <img src="/images/help/ats-setup/new-2026-09/hr-office/setup-24727324595345-04.png" alt="Use the Portal ID and API key from the API career site." width="760" />
</Frame>

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Export a test profile with a resume to a selected job, then verify the application in HR Office.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to HR Office, follow the [export steps](/exports) and select the connected ATS and intended job.
