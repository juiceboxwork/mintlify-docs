## About the integration

The BambooHR and Juicebox integration is designed to seamlessly connect both systems in a two-way sync. You can use the integration for three use cases:

1. **Import Project from ATS**: Import a job description from BambooHR into Juicebox to automatically kick off a search using the job description. This also includes linking your Juicebox project to an ATS job, which makes exporting profiles to your ATS easier. More details [here](/projects).
2. **Export Profiles to ATS**: Save profiles directly into BambooHR, including contact details, current company and job, profile URLs, and more. On some plans, this can be customized further based on your preferred fields. Juicebox also has the ability to auto-export to your ATS, including exporting all shortlisted profiles or exporting only interested profiles.
3. **Import Candidates**: View profiles already in BambooHR within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the BambooHR integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your BambooHR jobs and can select the corresponding option.

### Export profiles to BambooHR

Follow the regular [export](/exports) steps and select **Export to BambooHR** on either an individual profile or a bulk export. After exporting, you will see the profile created in your BambooHR account.

### View profiles already in BambooHR

Juicebox will tag profiles that already exist in BambooHR. You will see the last modified date, as well as the option to view the profile directly in BambooHR by clicking the **View in ATS** button.

## Create a new user for the integration

<Note>
  The permissions of BambooHR's integration depend on the access levels of the user who creates the connection. If you only want to grant minimal permissions, create a new user and assign that user to a newly created access level.
</Note>

1. Go to **People**, then click **New Employee**.

   <Frame>
     ![New Employee button in BambooHR](/images/help/ats-setup/bamboohr-2.png)
   </Frame>

2. Enter a valid email address for the user that you can access, and make sure you select **Allow Access to BambooHR**. Then click save.

   <Frame>
     ![Allow Access to BambooHR option](/images/help/ats-setup/bamboohr-3.png)
   </Frame>

3. To configure the user's permissions, click the cog button in the top right of BambooHR.

   <Frame>
     ![Settings cog in BambooHR](/images/help/ats-setup/bamboohr-4.png)
   </Frame>

4. On the **Settings** page, click **Access Levels** in the left sidebar.

   <Frame>
     ![Access Levels in the Settings sidebar](/images/help/ats-setup/bamboohr-5.png)
   </Frame>

5. Find the access level the user is in, or click the plus button to create a new one. Make sure you select **Custom Access Level** when creating a new access level.

   <Frame>
     ![Plus button to create a new access level](/images/help/ats-setup/bamboohr-6.png)
   </Frame>

   <Frame>
     ![Custom Access Level option](/images/help/ats-setup/bamboohr-7.png)
   </Frame>

6. Check the permissions the connection pop-up in Juicebox asks for.

   <Frame>
     ![Permissions requested in the connection pop-up](/images/help/ats-setup/bamboohr-8.png)
   </Frame>

   Then select the matching permissions in BambooHR:

   <Frame>
     ![Selecting permissions in BambooHR](/images/help/ats-setup/bamboohr-9.png)
   </Frame>

   If you do not want the integration to have access to any employee data, select **Direct Reports** in step 3 under **What this Access Level Can See**:

   <Frame>
     ![Direct Reports option under What this Access Level Can See](/images/help/ats-setup/bamboohr-10.png)
   </Frame>

7. Add the new user to the access level.

   <Frame>
     ![Adding an employee to the access level](/images/help/ats-setup/bamboohr-11.png)
   </Frame>

   Select the employee and press **Done**:

   <Frame>
     ![Selecting the employee and pressing Done](/images/help/ats-setup/bamboohr-12.png)
   </Frame>

## Connect BambooHR to Juicebox

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **BambooHR** and click **Activate**. You can also use the search bar at the top.
3. In the connection pop-up, press **Sign in with BambooHR**.

   <Frame>
     ![Sign in with BambooHR button in the connection pop-up](/images/help/ats-setup/bamboohr-13.png)
   </Frame>

4. A pop-up window appears. Enter the email and password of the account you created above and press **Log In**.

   <Frame>
     ![BambooHR login pop-up](/images/help/ats-setup/bamboohr-14.png)
   </Frame>

5. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated BambooHR and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and BambooHR.
</Note>
