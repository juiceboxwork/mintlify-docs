## About the integration

Connect Zvoove Recruit to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Use a Zvoove Recruit account with access to API keys and application-source catalogs. Have your instance’s domain ready.

Open **Integrations** in Juicebox, select **Zvoove Recruit**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

<Note>
The screenshots show vendor settings or the connection window provided by Kombo. Use the credentials, source labels, permissions, and URLs from your own connection; screenshot values are examples.

## Create the two API keys

1. Enter your Zvoove Recruit domain in Juicebox.
2. In Zvoove, open your profile menu and select **Einstellungen > Interfaces & Plugins > API-Keys**.
3. Use **+** to create a named key for **OpenBewerber** and save it.
4. Repeat for **OpenStelle**, then enter both keys in their matching Juicebox fields.

Open **Settings > Adjustments > Catalogs** and edit the application-source catalog. Add the source value shown in your connection window, save, and finish setup.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in Zvoove Recruit.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Zvoove Recruit, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
