## About the integration

Connect Databites to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Use an account that can manage integration settings in Databites Match. Determine your tenant slug from the first part of your Databites domain.

Open **Integrations** in Juicebox, select **Databites**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

<Note>
The screenshots show vendor settings or the connection window provided by Kombo. Use the credentials, source labels, permissions, and URLs from your own connection; screenshot values are examples.
</Note>

## Create the integration API key

1. Open **Match > Verwaltung > Einstellungen**.
2. Scroll across the settings tabs to **Integrationen**, then select **Neuen API-Key erstellen**.
3. Choose **Kombo** as the provider and use `databites:YOUR_TENANT_SLUG` as the Integration-ID.
4. Give the key a recognizable name. Select **Lesen & Schreiben** for the scope and **Kombo (Unified-API)** as the Default-Source. Fill in the source details that match your integration.
5. Select **Erstellen** and save the key securely; it is displayed only once.

## Connect Databites

Enter your tenant slug in Juicebox, followed by the API key and the same Integration-ID you used in Databites. Complete setup.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in Databites.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Databites, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
