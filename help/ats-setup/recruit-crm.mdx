## About the integration

Juicebox's integration with Recruit CRM allows you to:

1. **Export Profiles to Recruit CRM**: Save profiles directly into Recruit CRM, including contact details, current company and job, profile URLs, and more.
   1. **[Configurable] Auto-Export:** Juicebox has the ability to auto-export profiles to your ATS with configurable triggers, including after shortlisting, after adding to a sequence, or after an interested response.
   2. **Custom Integration Fields:** On some plans, integration fields can be customized further based on your preferred fields.
2. **Link Recruit CRM Jobs to Juicebox**
   1. **Import Job Descriptions**: Import a job description from Recruit CRM into Juicebox to automatically kick off a search using the job description.
   2. **Simplify Exports:** When exporting a profile from Juicebox to the ATS, it will automatically be connected to the correct job in the ATS. More details [here](/projects).
3. **View Profiles in Recruit CRM**: View profiles already in Recruit CRM within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Recruit CRM integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Recruit CRM jobs and can select the corresponding option.

### Export profiles to Recruit CRM

Follow the regular [export](/exports) steps and select **Export to Recruit CRM** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Recruit CRM account.

### View profiles already in Recruit CRM

Juicebox will tag profiles that already exist in Recruit CRM. You will see the last modified date, as well as the option to view the profile directly in Recruit CRM by clicking the **View in ATS** button.

## Before you start

Only the account owner of the Recruit CRM instance can set up a connection.

## Copy your API token

1. Log in to Recruit CRM.
2. Go to **Admin Settings**.
3. Go to **API & Integrations**.
4. Find the **API Token** section.
5. Enable the API token if it is not enabled yet, and confirm the page shows **API Token Is Active**.
6. Click **Copy** next to the API token.

   <Frame>
     ![Copying the API token in Recruit CRM](/images/help/ats-setup/recruit-crm-1.png)
   </Frame>

7. Paste the token into the connection pop-up.

   <Frame>
     ![Pasting the API token into the connection flow](/images/help/ats-setup/recruit-crm-2.png)
   </Frame>

8. Click **Set up Integration**.

## Setting up the integration

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Recruit CRM** and click **Activate**. You can also use the search bar at the top.
3. Follow the instructions in the connection pop-up, pasting your API token when prompted.
4. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Recruit CRM and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Recruit CRM.
</Note>
