## About the integration

Connect Paradox to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Use an account that can view **My Profile > Settings** and **Jobs Manager**. You will need the existing Account ID and API Secret, plus a jobs feed URL when job import is in scope.

Open **Integrations** in Juicebox, select **Paradox**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Copy the existing Account ID and API Secret

Open your user menu, select **My Profile > Settings**, and copy the **Account ID** and **API Secret**. Do not generate a replacement secret as part of routine setup: doing so can break other integrations using the existing secret.

## Prepare the jobs XML feed

1. Open **All Apps > Settings > Jobs > Jobs Manager**.
2. In **Job Distribution**, open the menu beside **Standard Job Feed** and select **Copy account level feed**.
3. Open the account-level field configuration and enable **jobreqid** so the feed contains the job identifier.

## Enter the credentials and region

Enter the Account ID and API Secret in Juicebox, select the API URL for your environment, and provide the jobs feed URL when requested. Production APIs commonly use `api.paradox.ai` or `api.eu1.paradox.ai`; select the region used by your account.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in Paradox.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Limitations

Only CV attachments are supported. Uploading a new CV replaces the existing CV. Some job details may be unavailable in the XML feed.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Paradox, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
