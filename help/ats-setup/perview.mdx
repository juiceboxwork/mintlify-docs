## About the integration

Connect Perview to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. This connector does not provide full-database candidate reading for rediscovery.

## Before you start

Ask Perview to supply the **Jobs API URL** for public jobs and the **username** and **API key** for the Form API. An administrator must also configure candidate sources.

Open **Integrations** in Juicebox, select **Perview**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Create and activate the source

1. Copy the source label from the connection window.
2. In Perview, open **My Company > Company > Add/Sort Sources**.
3. Add the label, move it into **Active Sources**, mark it as **Default**, and save.

## Add the source to existing jobs

For the job identified by the connection check, open **Settings > Application Form > Sources > Add Source**, select the new source, and save. Repeat for all existing jobs you will use. Setting the source as default applies it to future jobs, but does not update existing jobs. Finish setup in Juicebox.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Export a test profile with a resume to a selected job, then verify the application in Perview.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Perview, follow the [export steps](/exports) and select the connected ATS and intended job.
