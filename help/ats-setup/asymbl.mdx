## About the integration

Connect Asymbl to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Ask your Asymbl customer success manager for a **Client ID** and **Client Secret**. Your Salesforce administrator may also need to check the connected app’s access.

Open **Integrations** in Juicebox, select **Asymbl**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Find the Salesforce instance URL

1. Sign in to Asymbl and open **Your profile** in the upper-right corner.
2. Copy the instance URL shown in the profile pop-up, usually ending in `.my.salesforce.com`. This can differ from the address used to sign in.
3. Enter this instance URL in Juicebox.

Enter the **Client ID** and **Client Secret** supplied by Asymbl and select **Set up integration**.

## Resolve Salesforce permissions if needed

If authorization fails, ask your administrator to check the Asymbl-provided app in **App Manager**. Confirm that OAuth is enabled and the selected scopes include **Manage user data via APIs (api)**. Match the remaining app policies and user permissions to your current connection instructions.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in Asymbl.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Limitations

An existing candidate with the same email is reused; their profile is not updated by creating another application.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Asymbl, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
