## About the integration

Connect CareerPlug to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

Check that **Settings > Integrations > API Applications** is available in CareerPlug. If it is missing, ask [CareerPlug support](mailto:support@careerplug.com) or your representative to enable access for your organization.

Open **Integrations** in Juicebox, select **CareerPlug**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

<Note>
The screenshots show vendor settings or the connection window provided by Kombo. Use the credentials, source labels, permissions, and URLs from your own connection; screenshot values are examples.

## Register an API application

1. Open **Settings > Integrations > API Applications > Add New Application**.
2. Use the help icon beside **Native Redirect URI** to find the redirect URI for your account. Copy it exactly.
3. Name the application **Juicebox**, enter the copied Redirect URI, and create the application.

## Connect the application

Open **Credentials** beside the new application. Copy the **Application** and **Secret** values into their corresponding fields in Juicebox and continue.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in CareerPlug.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Limitations

A single CV is required when creating a candidate. Other attachment types are not supported.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to CareerPlug, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
