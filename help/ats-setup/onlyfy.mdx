## About the integration

Connect Onlyfy to Juicebox to import job descriptions into your searches and identify profiles that already exist in your ATS.

You can also export profiles to a selected Onlyfy job.

If Onlyfy is not visible in your Juicebox Integrations tab, contact [Juicebox Support](mailto:support@juicebox.ai) to confirm availability for your account.

## Before you start

You need an **administrator** account in Onlyfy to create an API key. Keep the Juicebox connection pop-up open so you can refer to the permissions it requests.

## Create an Onlyfy API key

1. In Juicebox, open **Integrations**, select **Onlyfy**, and click **Activate**. Find the required permissions in the connection pop-up.
2. In Onlyfy, click the cog in the top-right corner to open settings.
3. Go to **Integrations > REST API**.
4. Click **Create new API Key**.
5. Enter a name and reporting name for this connection, such as **Juicebox**.
6. Select the permissions listed in your Juicebox connection pop-up, then save the key.
7. Find the newly created key under the name you chose and copy it.

## Setting up the integration

1. Return to the Juicebox connection pop-up and paste the API key.
2. Complete the remaining prompts.
3. Return to Juicebox and confirm that the integration shows **Connected**.

## Confirm the integration

After the initial sync, check that the expected jobs appear and an existing Onlyfy candidate is identified in Juicebox.

If the connection reports missing permissions, compare the key's permissions in Onlyfy with the list in your connection pop-up. Update the key and retry the connection.

## Using the integration

To start a search from a job, open **Projects** and select **Import Job from ATS / CRM**, then choose the relevant Onlyfy job.

Juicebox identifies profiles that already exist in Onlyfy, helping your team check for existing records before reaching out.

To send a profile to Onlyfy, follow the [export steps](/exports) and choose the Onlyfy export option for the linked job. Confirm that the profile appears in Onlyfy after the export completes.

<Note>
The initial sync can take time. Data may continue to appear after the connection is established. If you do not see the expected records, contact Juicebox Support.
</Note>
