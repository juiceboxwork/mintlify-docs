## About the integration

Connect Abacus Umantis to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

An Umantis administrator must approve the API connection. Check that your settings menu includes **Main settings**.

Open **Integrations** in Juicebox, select **Abacus Umantis**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

<Note>
The screenshots show vendor settings or the connection window provided by Kombo. Use the credentials, source labels, permissions, and URLs from your own connection; screenshot values are examples.

## Enter your Umantis subdomain

1. Sign in to Umantis and copy the part of the address before `.umantis.com`.
2. Enter that subdomain in the Juicebox connection window and continue.

## Approve the partner API account

1. In Umantis, open the settings menu, then **Settings > Main settings > API**.
2. Find the pending entry under **Partner API account** and select **Accept**.
3. Confirm with **Accept** on the following screen, then continue in Juicebox.

## Configure the source when prompted

1. Open the **How did you hear about us?** page linked from your connection window.
2. Select **Actions > Add selection value**.
3. Enter the exact value supplied by the connection window in each requested language field, save it, and return to Juicebox.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in Abacus Umantis.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Limitations

PDF attachments work by default. Other formats may require additional setup. Up to 14 extra attachments are supported in addition to the CV and cover letter.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to Abacus Umantis, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
