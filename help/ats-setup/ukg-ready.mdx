## About the integration

Connect UKG Ready to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

A UKG Ready administrator must create a security profile and OAuth application. Keep the required permission list in your Juicebox connection window open.

Open **Integrations** in Juicebox, select **UKG Ready**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Create the security profile

1. Search for **security** and select **Security (Profiles / Policies)**.
2. Choose **New Security Profile**.
3. Apply the permissions listed in your connection window. The relevant areas can include **Modules > REST API Resources**, **HR > Recruitment**, **HR > Employee Management**, and **Reports > Reports**.
4. Name and save the profile, then continue in Juicebox.

## Create the OAuth application

1. Open **Global Setup > Company Setup**. If the **OAuth Applications** panel is missing, use **Edit Tabs** to add it from Available Windows.
2. Select **Add OAuth Application**, complete the requested information, and assign the security profile you created.
3. Generate the application secret and copy its **Client ID** and **Secret** into Juicebox.
4. Save the application in UKG Ready first, then complete the connection in Juicebox.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in UKG Ready.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Limitations

The API returns only publicly visible jobs; closed jobs are not available.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to UKG Ready, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
