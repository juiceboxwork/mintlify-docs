## About the integration

The Ceipal and Juicebox integration is designed to seamlessly connect both systems in a two-way sync. You can use the integration for three use cases:

1. **Import Project from ATS**: Import a job description from Ceipal into Juicebox to automatically kick off a search using the job description. This also includes linking your Juicebox project to an ATS job, which makes exporting profiles to your ATS easier. More details [here](/projects).
2. **Export Profiles to ATS**: Save profiles directly into Ceipal, including contact details, current company and job, profile URLs, and more. On some plans, this can be customized further based on your preferred fields. Juicebox also has the ability to auto-export to your ATS, including exporting all shortlisted profiles or exporting only interested profiles.
3. **Import Candidates**: View profiles already in Ceipal within Juicebox. Avoid reaching out to the same profile twice, and instantly view your relationship history.

### Start a project via the Ceipal integration

Open the projects page and select **Import Job from ATS / CRM**. You will then see your Ceipal jobs and can select the corresponding option.

### Export profiles to Ceipal

Follow the regular [export](/exports) steps and select **Export to Ceipal** on either an individual profile or a bulk export. After exporting, you will see the profile created in your Ceipal account.

### View profiles already in Ceipal

Juicebox will tag profiles that already exist in Ceipal. You will see the last modified date, as well as the option to view the profile directly in Ceipal by clicking the **View in ATS** button.

## Obtain your API key

1. Log in to Ceipal ATS.
2. Click on your profile in the upper right section of Ceipal.
3. Click **Admin Setup**.

   <Frame>
     ![Admin Setup in the Ceipal profile menu](/images/help/ats-setup/ceipal-1.png)
   </Frame>

4. Hover over **API Settings**, then click **API Access Configuration**.

   <Frame>
     ![API Access Configuration under API Settings](/images/help/ats-setup/ceipal-2.png)
   </Frame>

5. Click the copy icon next to **Your API Key** and save the value.

   <Frame>
     ![Copying the API key in Ceipal](/images/help/ats-setup/ceipal-3.png)
   </Frame>

## Set up the ability to create applicants

You should still be in the **API Settings** section after the previous step.

1. Click **Custom API Configuration**, then click **Add**.

   <Frame>
     ![Custom API Configuration with the Add button](/images/help/ats-setup/ceipal-4.png)
   </Frame>

2. Give the API a name.
3. Select **Applicants** in the dropdown.
4. Select the **POST(Push to Ceipal)** method.
5. Make sure **Send all fields** is ticked.
6. Click **Save**.
7. Copy the value for **API Full URL**.

   <Frame>
     ![Custom API configuration form with the API Full URL](/images/help/ats-setup/ceipal-5.png)
   </Frame>

## Connect Ceipal to Juicebox

1. Navigate to the **Integrations** tab on the Juicebox platform.
2. Select **Ceipal** and click **Activate**. You can also use the search bar at the top.
3. In the connection pop-up, enter the email and password you use to log in to Ceipal. If you have configured a separate API-only password in the API Access Configuration settings, use that password instead.

   <Frame>
     ![Entering your Ceipal email and password in the connection pop-up](/images/help/ats-setup/ceipal-6.png)
   </Frame>

4. Enter the API key you obtained in the Admin portal of Ceipal.

   <Frame>
     ![Entering the Ceipal API key](/images/help/ats-setup/ceipal-7.png)
   </Frame>

5. Enter the custom API URL you generated in the Admin portal.

   <Frame>
     ![Entering the custom API URL](/images/help/ats-setup/ceipal-8.png)
   </Frame>

6. After you have clicked through the remaining pages of the pop-up, the configuration will be completed. If successful, you will see a green **Connected** button in your Integrations marketplace.

Congratulations! You have successfully integrated Ceipal and Juicebox.

<Note>
  It may take a few minutes for all data to sync between Juicebox and Ceipal.
</Note>
