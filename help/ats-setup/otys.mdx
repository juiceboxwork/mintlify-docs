## About the integration

Connect OTYS to Juicebox to import jobs and start searches from their job descriptions. You can also export profiles with resumes to a selected job. Existing candidates can be identified in Juicebox and used for rediscovery, subject to the access granted to the connection.

## Before you start

OTYS support issues the API key. Its support service may charge for this request; confirm the current terms with OTYS before ordering work.

Open **Integrations** in Juicebox, select **OTYS**, and choose **Activate**. Keep the connection window open while completing the steps below. If the integration is not visible, ask [Juicebox Support](mailto:support@juicebox.ai) to confirm access for your account.

## Request an API key with the right services

1. In the OTYS dashboard, select **Configure boards**.
2. Under **Other**, add the **Support** widget if it is not already visible.
3. Select the widget’s **+** button and open a **Question** ticket.
4. Request an API key for Juicebox through Kombo and include the complete service list shown in your connection window.

## Enable consent writing only if required

If your workflow needs to write GDPR consent status and dates, ask the OTYS account manager to enable **Partner permission for updating GDPR due dates** on the key. Identify the OTYS user who created the key. Only OTYS can enable this permission.

## Confirm the integration

Finish the connection window and return to Juicebox. Confirm that the connection has completed, then allow the initial sync to populate your data.

- Check that the expected jobs appear in Juicebox.
- Find a known candidate and confirm that the information available matches your configured access.
- Export a test profile with a resume to a selected job, then verify the application in OTYS.

If validation fails, check the credentials, account or region, and permission list shown in the connection window. Contact Juicebox Support if the expected data is still missing.

## Using the integration

Start from an imported job on the [Projects](/projects) page to create a search linked to that job.

To send a profile to OTYS, follow the [export steps](/exports) and select the connected ATS and intended job.

Learn how to work with existing candidates in [Talent Rediscovery](/talent-rediscovery).
