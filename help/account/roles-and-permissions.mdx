Juicebox has multiple roles and permissions, depending on the account type and configuration.

## Default roles in Juicebox

Roles are organized into four permission levels: **Admin, Read-Only Admin, Licensed Seat, and Hiring Manager**. The most commonly assigned role is **Licensed Seat**, which provides full access to Juicebox's core sourcing workflows, including candidate search, project creation and management, candidate review, shortlisting, and outreach execution.

![Role options when inviting a team member](/images/help/account/roles-and-permissions-1.png)

<Note>
  The Read-Only Admin and Hiring Manager licenses are view-only, and will not be able to perform any sourcing or outreach activity across candidates or the platform. Learn more about [Hiring Manager seats](/hiring-managers).
</Note>

## Read-Only Admin access to Agent projects

Read-Only Admins can review Agent-backed projects alongside regular projects, without being able to change them.

- **All Projects list.** Agent-backed projects appear in the list. Row metrics (shortlisted, contacted, interested) and the "leads awaiting review" count are visible but not clickable, and the row-level actions menu is hidden.
- **Inspect-only project view.** Opening an Agent-backed project shows the project home, agent status, owners, and shortlist and outreach metrics. Juicebox locks composer submissions, configuration edits, and the create, pause, and close agent actions. You cannot start a new search or launch a review from the shortlist.
- **API enforcement.** The same limits apply to the underlying APIs. Requests from a Read-Only Admin to create or mutate an agent, launch a search, or launch a review return `403 Access denied for view-only admins`. Scripted access follows the same boundary as the UI.
- **Regular projects.** Projects without an agent are unchanged. Read-Only Admins can open them and use the actions the role already allowed, such as editing collaborators.

### Projects analytics

Read-Only Admins with the Analytics permission (see below) also see Agent-backed projects in the Projects analytics tab. When you turn on the **Show Agents only** filter, Juicebox labels the overview total **Agent-backed projects**. The total includes open and closed Agent-backed projects for the selected date range. Hover the tile for a reminder that this is a date-based total, not a live agent count.

## Special permissions: Agents, tags and analytics

An admin license (including read-only) can grant individual team members access to agents and/or analytics. To manage permissions:

1. Click on your name in the bottom left > **Account Settings**.
2. Navigate to [Team members](https://app.juicebox.ai/account?tab=org).
3. Select the settings gear icon for the profile you'd like to change permissions for (first icon under **Actions**).
4. Select or unselect **Analytics** or **Agents**, or assign a tag to any team member as needed.

![Manage member permissions from Team members](/images/help/account/roles-and-permissions-2.png)

To change who the admin is, see [Change the admin user](/help/account/change-admin-user).
