Juicebox has multiple roles and permissions, depending on the account type and configuration.

## Default roles in Juicebox

Roles are organized into four permission levels: **Admin, Read-Only Admin, Licensed Seat, and Hiring Manager**. The most commonly assigned role is **Licensed Seat**, which provides full access to Juicebox's core sourcing workflows, including candidate search, project creation and management, candidate review, shortlisting, and outreach execution.

![Role options when inviting a team member](/images/help/account/roles-and-permissions-1.png)

<Note>
  The Read-Only Admin and Hiring Manager licenses are view-only, and will not be able to perform any sourcing or outreach activity across candidates or the platform. Learn more about [Hiring Manager seats](/hiring-managers).
</Note>

## Inviting an Admin directly

Admins and view-only admins can invite a new teammate straight into the **Admin** role from **Account Settings** → **Team Members**. In the invite role dropdown, select **Admin (Licensed seat)** and send the invite.

- Admin invites consume a licensed seat from the same pool as regular members, so confirm a seat is available before inviting.
- Only admins and view-only admins can send Admin invites. Other roles do not see this option in the dropdown.
- Pending admin invites appear with an **Admin** role label in the Team Members list. Once the invitee accepts, they receive full admin permissions with no follow-up role change.

If you only need to grant admin access to someone already on your team, see [Change the admin user](/help/account/change-admin-user).

## Special permissions: Agents, tags and analytics

An admin license (including read-only) can grant individual team members access to agents and/or analytics. To manage permissions:

1. Click on your name in the bottom left > **Account Settings**.
2. Navigate to [Team members](https://app.juicebox.ai/account?tab=org).
3. Select the settings gear icon for the profile you'd like to change permissions for (first icon under **Actions**).
4. Select or unselect **Analytics** or **Agents**, or assign a tag to any team member as needed.

![Manage member permissions from Team members](/images/help/account/roles-and-permissions-2.png)

To change who the admin is, see [Change the admin user](/help/account/change-admin-user).
