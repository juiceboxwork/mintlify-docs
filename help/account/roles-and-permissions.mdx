Juicebox has multiple roles and permissions, depending on the account type and configuration.

## Default roles in Juicebox

Roles are organized into four permission levels: **Admin, Read-Only Admin, Licensed Seat, and Hiring Manager**. The most commonly assigned role is **Licensed Seat**, which provides full access to Juicebox's core sourcing workflows, including candidate search, project creation and management, candidate review, shortlisting, and outreach execution.

![Role options when inviting a team member](/images/help/account/roles-and-permissions-1.png)

<Note>
  The Read-Only Admin and Hiring Manager licenses are view-only, and will not be able to perform any sourcing or outreach activity across candidates or the platform. Learn more about [Hiring Manager seats](/hiring-managers).
</Note>

### Pausing and closing Agents as a Read-Only Admin

Read-Only Admins can pause, resume, and close Agents. Use the Agent actions menu on the **Projects** list or on the Agent card of a project page.

Read-Only Admins still can't change Agent settings, reopen a closed Agent, or open the Agent pages. Hiring Managers and sequence seats can't pause, resume, or close Agents.

## Special permissions: Agents, tags and analytics

An admin license (including read-only) can grant individual team members access to agents and/or analytics. To manage permissions:

1. Click on your name in the bottom left > **Account Settings**.
2. Navigate to [Team members](https://app.juicebox.ai/account?tab=org).
3. Select the settings gear icon for the profile you'd like to change permissions for (first icon under **Actions**).
4. Select or unselect **Analytics** or **Agents**, or assign a tag to any team member as needed.

![Manage member permissions from Team members](/images/help/account/roles-and-permissions-2.png)

Each team member can have up to 10 tags.

### Filter and sort team members by tag

Use tags to find groups of team members quickly, such as everyone on one team or in one office.

1. On the **Team members** page, click **Filter** next to the search bar.
2. Open the **Tags** submenu. Each tag shows how many members have it.
3. Select one or more tags. The selected tags appear as chips below the search bar.

To remove a tag from the filter, click the remove button on its chip. Click **Clear all** to remove every tag filter.

To sort members by tag, click the **Tags** column header. Click it again to reverse the order. Members without tags always appear last.

### Add or remove tags in bulk

Admins can add or remove tags for many team members at once.

1. On the **Team members** page, select the checkbox next to each member you want to update. To select every row that matches your current search and filters, use the checkbox in the table header.
2. In the action bar at the bottom of the page, click **Add tags** or **Remove tags**.
3. Pick the tags to add or remove. When adding, you can choose existing tags or create new ones.
4. Review the summary, then click **Add to** or **Remove from** to confirm.

Before you confirm, the dialog shows how many members will change. Members who would go over the 10-tag limit are skipped, and the dialog shows how many will be skipped. You can update up to 1,000 members in one bulk action.

<Note>
  Members hidden by your search or tag filters are removed from the selection. Clearing a filter does not add them back.
</Note>

To change who the admin is, see [Change the admin user](/help/account/change-admin-user).
