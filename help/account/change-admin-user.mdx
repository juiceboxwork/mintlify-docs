Organizations can have multiple admin users, each with permissions to manage the workspace. If you need to give admin access to another team member, or remove admin access from someone, our support team can help make this change.

## Requesting an admin change

To add or change admin users for your organization:

1. Contact our support team via the in-app chat or at [support@juicebox.ai](mailto:support@juicebox.ai).
2. Specify which team member(s) should receive admin access, and whether any existing admins should have their admin access removed.
3. If the new admin is not yet a member of your organization, provide their email address so we can invite them.

<Note>
  Organizations can have more than one admin user at a time. Adding a new admin doesn't affect existing admins. If you remove an admin's access, they keep regular user access unless you also remove them from the organization.
</Note>

## What happens when admin access changes

When admin access is added or removed:

- New admins receive full administrative permissions.
- Existing admins keep their admin access unless you ask us to remove it.
- Admins whose admin access is removed become regular users.
- All organization content and data remains unchanged.

If a new admin isn't currently a member of your organization, they'll receive an email invitation to create an account before being granted admin access.

To learn what each role can do, see [Account roles and permissions](/help/account/roles-and-permissions).
