Organizations can have one admin user who has special permissions to manage the workspace. If you need to transfer admin access to another team member, our support team can help make this change.

## Requesting an admin change

To change the admin user for your organization:

1. Contact our support team via the in-app chat or at [support@juicebox.ai](mailto:support@juicebox.ai).
2. Specify which team member should receive admin access.
3. If the new admin is not yet a member of your organization, provide their email address so we can invite them.

<Note>
  Organizations can only have one admin user at a time. The previous admin will retain regular user access unless specifically removed from the organization.
</Note>

## What happens during the transfer

When the admin access is transferred:

- The new admin will receive full administrative permissions.
- The previous admin's access will be converted to regular user status.
- All organization content and data remains unchanged.

If the new admin isn't currently a member of your organization, they'll receive an email invitation to create an account before being granted admin access.

To learn what each role can do, see [Account roles and permissions](/help/account/roles-and-permissions).
